# 1 文档概述

## 1.1 目的

本文档详细描述海外保险数字化平台"渠道管理"模块下 **渠道档案** 和 **渠道合作** 两个子模块的全部页面、交互、字段、校验规则和业务逻辑，作为渠道域 PRD 的**样稿**（后续渠道授权/培训/合规/结算/政策/数据分析各章按本样稿骨架续写），指导后续 UI 设计、研发实施和测试验收。

## 1.2 范围

| 子模块 | 覆盖页面 | 对应需求基线 |
|---|---|---|
| 渠道档案 | 列表页、新增/编辑表单（4 步骤）、详情页（8 个 Tab）、组织层级页（6 个 Tab）、批量导入、状态变更弹窗 | 功能点 7 项：渠道档案管理 / 法律实体子表 / 联系人子表 / 业务员 Individual Producer 子表（本期建设）/ 资质文件子表 / 银行账户子表 / 组织层级 |
| 渠道合作 | 合作列表页、协议新增/编辑表单、合作详情页（4 个 Tab）、续约登记弹窗、协议到期预警列表 | 功能点 6 项：合作协议管理 / 合作范围 / 结算条款只读+跳转 / 协议附件 / 续约登记 / 协议到期预警 |

**模块边界说明：** 渠道订单（询价/成交）内嵌于渠道结算子模块（需求基线口径），本样稿不覆盖；渠道入驻与准入、渠道绩效考核、渠道门户 Portal 本期移出渠道管理范围（附录 B 说明）；结算条款在渠道合作详情页**只读展示**，唯一编辑入口为财务模块渠道结算主数据页。

## 1.3 用户角色

| 角色 | 本模块权限 |
|---|---|
| 平台超级管理员 | 全部操作 |
| 渠道运营 | 渠道档案 CRUD、提交审核、层级管理、联系人/业务员维护、协议 CRUD、续约登记、批量导入导出 |
| 渠道合规专员 | 查看档案详情、资质文件审核、暂停/终止/黑名单发起、变更历史审计查询 |
| 佣金财务 | 查看银行账户、结算条款摘要（只读），结算条款维护跳转财务模块 |
| 国际化管理员 | zh-CN 翻译维护、术语审核、双语验收、businessCountry 字段集配置 |

> 数据权限：平台运营角色可查看全平台数据；businessCountry（US/CN）数据相互隔离，运营角色可同时访问，但 UI 字段集按 businessCountry 动态显示。

## 1.4 核心术语

| 术语 | 定义 |
|---|---|
| Channel / 渠道 | 我司下游分销渠道组织（Agency/MGA/MGU/Surplus Lines Broker/Wholesaler/Direct Writer/TGA） |
| Individual Producer | 业务员个体（区分渠道机构与业务员个体），美国监管口径下的持牌自然人 |
| NPN | National Producer Number，全美业务员唯一编号，由 NIPR 管理 |
| NIPR | National Insurance Producer Registry，全美保险业务员注册中心，提供牌照查询 API |
| FEIN | Federal Employer Identification Number，联邦雇主识别号（同 EIN） |
| Business Entity License | 法人实体牌照，渠道机构持有的州级保险经营牌照（区别于 Individual Producer License） |
| Appointment | 保险公司在州监管层面对业务员的授权；美国口径下业务员是 Individual Appointment，不是机构 Appointment |
| LOA | Line of Authority，牌照授权线（如 AUTO/HOME/LIFE） |
| CE | Continuing Education，继续教育，业务员周期完成 CE 学时维持 License 有效性 |
| E&O Insurance | Errors & Omissions，职业责任险 |
| W-9 | IRS 表格 W-9，提供纳税人识别号（TIN），用于 1099 年报 |
| LOB | Line of Business，业务线（Auto/Home/Life/Health 等） |
| Routing Number | ABA 银行路由号（US 银行账户必填） |
| businessCountry | 业务国别字段：US/CN，数据层口径；与 UI 语言（中/英）独立 |

## 2.3 businessCountry 分轨与语言策略

1. **businessCountry（US/CN）为数据层口径**，贯穿渠道档案所有主数据与子表（法律实体/联系人/业务员/资质文件/银行账户/合作协议均携带）。
2. **UI 层按 businessCountry 动态显示字段集**：US 显示 FEIN/Resident State/Business Entity License Number/Checking-Savings-Escrow 等；CN 显示统一社会信用代码/注册地/营业执照号/基本户-一般户等。CN 字段集本期仅做**预留展示**，完整业务流程建设延后。
3. **businessCountry 与语言切换（中/英）解耦**：支持"US 业务 + 中文界面"组合；所有文案进翻译文件（react-i18next，channel 命名空间，Key 前缀 `ch`），页面不得硬编码。
4. 语言选择 LocalStorage 持久化，刷新不丢失；en-US 为基准语言包，zh-CN 对称翻译。

## 2.4 通用交互约定

| 场景 | 约定 |
|---|---|
| 空态 | 列表/Tab 无数据时显示居中插图 + 引导文案（如"暂无法律实体，点击右上角新增"）+ 主操作按钮 |
| 加载态 | 列表首次加载显示骨架屏；Tab 切换/弹窗打开显示 Spinner（Loader2 图标旋转） |
| 错误态 | 接口失败显示行内红色错误条（AlertCircle 图标 + "加载失败，点击重试"），不弹全局遮罩 |
| 无权限 | 无操作权限的按钮隐藏或禁用（tooltip 提示"无权限"）；直接访问无权页面显示 403 插图页 |
| 并发编辑 | 表单提交时携带 `updated_at` 乐观锁版本号；版本冲突时提示"该档案已被 {操作人} 于 {时间} 更新，请刷新后重试"，本地不覆盖远端 |
| 审计留痕 | 档案字段变更、状态变更、子表增删改、文件上传替换均记录变更历史（操作人/角色/时间/IP/旧值→新值/备注），不可删除，保留 ≥ 5 年 |
| 危险操作 | 终止、加入黑名单、删除类操作使用红色主按钮 + 二次确认对话框（红色警告框显示对象名称） |
| 会话过期 | 提交时 401 自动 refresh 重试；refresh 失败清除会话跳转登录页，按钮不得卡在"提交中" |
| 数字与编码 | 金额、NPN、FEIN、Routing Number、邮编等数据一律使用 JetBrains Mono 等宽字体 |

# 3 渠道档案子模块

## 3.1 渠道列表页

> 原型参考：`ChannelList.tsx`（树形列表）、`ChannelMasterView.tsx` OrgListTab（主数据列表）。两页能力在 V1.0 合并为统一列表页，字段以本章为准。

### 3.1.1 页面布局

页面从上到下依次为：**页头区** → **KPI 指标行** → **搜索筛选栏** → **批量操作栏**（选中时显示）→ **数据表格**（父子行树形展开）→ **分页**。最大宽度 1440px 居中。

### 3.1.2 页面目的与入口

- **目的：** 渠道档案的全局检索、状态监控与批量管理入口，支持按渠道层级树浏览上下级关系。
- **入口：** 侧边栏「渠道管理 → 渠道列表」；保险公司详情页 Tab 4 合作渠道的渠道名称链接。
- **权限：** 渠道运营/超级管理员可见全部操作；合规专员只读 + 状态操作；佣金财务只读。

### 3.1.3 页头区

| 元素 | 说明 |
|---|---|
| 标题 | "渠道列表"（en: Channels） |
| 副标题 | "共 X 个渠道 · Y 个活跃" |
| 操作按钮组（右对齐） | **批量导入**（btn-secondary，跳转 3.5）、**导出**（btn-secondary，按当前筛选导出 Excel）、**新增渠道**（btn-primary，跳转 3.2） |

**交互：**
- 点击"批量导入"→ 跳转批量导入页（模板按 businessCountry 区分）
- 点击"导出"→ 按当前筛选条件异步导出，完成后下载 Excel
- 点击"新增渠道"→ 跳转渠道新增表单页

### 3.1.4 KPI 指标行

4 列等宽网格，玻璃态卡片（对齐原型）：

| 指标 | 格式化 | 副信息 |
|---|---|---|
| 渠道总保费 | $X.XM（仅顶级渠道汇总） | MoM/YoY 增长率（绿色 ↑） |
| 活跃渠道 | N | "共 X 个渠道" |
| 总业务员人数 | 千分位（含子渠道合计） | "在职 Individual Producer" |
| 平均续保率 | XX.X%（活跃渠道均值） | "vs 基准 80%" |

### 3.1.5 搜索筛选栏

卡片容器，内部水平排列，自动换行。

| 控件 | 类型 | 说明 |
|---|---|---|
| 搜索框 | 文本输入 | 占位符"搜索渠道名称、NPN 编码…"，左侧 Search 图标，模糊匹配渠道英文名/中文名/简称/NPN/渠道编号 |
| businessCountry | 下拉选择 | 选项：全部 / US / CN（默认全部） |
| 渠道类型 | 下拉选择 | 选项：全部 / Agency / MGA / MGU / Surplus Lines Broker / Wholesaler / Direct Writer / TGA（CN 预留：代理/经纪/银保等） |
| 渠道状态 | 下拉选择 | 选项：全部 / 草稿（draft）/ 待审核（pending_review）/ 有效（active）/ 暂停（suspended）/ 终止（terminated）/ 黑名单（blacklisted） |
| 渠道等级 | 下拉选择 | 选项：全部 / Platinum / Gold / Silver / Standard（原型已有字段，保留） |
| 大区 | 下拉选择 | 选项：全部 / Northeast / Southeast / Midwest / West |
| 重置按钮 | 文字按钮 | 红色文字 + XCircle 图标，仅当任一筛选条件非默认值时显示 |

**交互：**
- 任一筛选条件变化时自动重置到第 1 页；搜索为实时过滤（onChange 触发）
- 所有筛选条件之间为 AND 关系

### 3.1.6 数据表格

#### 表头列

| 列名 | 宽度 | 对齐 | 可排序 | 说明 |

### 3.5.4 确认导入与结果

- 仅"成功"行可确认导入；"失败"行下载错误报告修正后重新上传
- 确认导入 → 进度条（异步任务）→ 完成后结果页（成功 N / 失败 M / 跳过 K）+ "下载导入回执"
- 导入产生的新档案进入**待审核**状态；导入记录写入变更历史（changeType=import）

### 3.5.5 异常分支

- 文件格式不符/超限：上传即拦截并提示
- 全部行失败：确认按钮禁用，提示"无有效数据行"
- 重复导入：NPN/FEIN/渠道编号已存在且未软删除时该行跳过（skipped），不覆盖已有档案

## 3.6 渠道状态机与页面表现

### 3.6.1 状态机

```
draft（草稿） ──提交审核──→ pending_review（待审核） ──审核通过──→ active（有效）
     ↑                              │ 驳回（需原因）                  │
     └──────────────────────────────┘                    暂停操作（需原因） │
                                                         ↓              │
                                                  suspended（暂停） ←────┘
                                                         │              │
                                                   恢复操作│         终止操作（终态）
                                                         ↓              ↓
                                                     active（有效）  terminated（终止）
                                                        
                                          active/suspended ──加入黑名单（需审批，终态）──→ blacklisted
```

### 3.6.2 状态的页面表现

| 状态 | 列表 orb | 详情页可用操作 | 约束 |
|---|---|---|---|
| 草稿 draft | 灰 | 提交审核、编辑、删除 | 不参与业务；不出现在授权/合作可选渠道中 |
| 待审核 pending_review | 黄 | 审核通过、驳回（需原因） | 提交后进入运营审核流程，通常 1-3 个工作日（对齐原型文案） |
| 有效 active | 绿 | 暂停、加入黑名单、编辑、终止 | 可正常开展授权/合作/结算 |
| 暂停 suspended | 红 | 恢复、终止、加入黑名单 | 合规异常或运营操作触发；暂停原因必填；暂停期间新单 Binding 冻结（联动授权模块） |
| 终止 terminated | 深灰 | 查看变更历史 | 终态，不可恢复；终止原因必填 |
| 黑名单 blacklisted | 黑 | 查看变更历史 | 终态，重大合规违规，需合规专员发起 + 审批 |

### 3.6.3 状态变更弹窗（对齐原型 StatusModal，含影响预览）

| 元素 | 说明 |

## 4.6 协议状态机与页面表现

### 4.6.1 状态机

```
draft（草稿） ──提交签署──→ pending_sign（待签） ──签署登记（上传签署附件）──→ signed（已签署）
                                                                              │ 到达生效日期自动 / 手动推进
                                                                              ↓
                                            expired（已到期） ←──到期── active（已生效） ──到期前90天──→ expiring（即将到期）
                                                                  ↑                        │                    │
                                                        续约登记（回到已生效）←──────────────┘                    │
                                                                              终止操作（需原因，终态）              │
                                                                                  ↓                             │
                                                                          terminated（已终止）                    │
                                                                                                                  │
                                            active ──废止（重大违约/合规要求，需审批，终态）──→ void（已废止）←──────┘（expiring 同样可终止/废止）
```

> 数据模型（12.3）状态枚举为 DRAFT / PENDING_SIGN / SIGNED / ACTIVE / EXPIRING / EXPIRED / TERMINATED / VOID（八态）；"已签署（SIGNED）"为独立状态值，签署登记（上传签署附件）后由 PENDING_SIGN 推进至 SIGNED，到达生效日期再推进至 ACTIVE。

### 4.6.2 状态的页面表现

| 状态 | orb 颜色 | 可用操作 | 约束 |
|---|---|---|---|
| 草稿 draft | 灰 | 编辑、提交签署、删除 | 不产生任何业务效力 |
| 待签 pending_sign | 黄 | 签署登记、编辑 | — |
| 已签署 signed | 黄 | 生效推进、编辑 | 等待生效日期 |
| 已生效 active | 绿 | 续约登记、终止、废止、创建补充协议 | 现行协议；结算/授权合作关系基础 |
| 即将到期 expiring | 橙 | 续约登记、终止、废止 | 到期前 90 天自动派生；进入到期预警列表 |
| 已到期 expired | 深灰 | 续约登记（补登记） | 终态之一；续约可回退到已生效 |
| 已终止 terminated | 红 | — | 终态，不可恢复 |
| 已废止 void | 红 | — | 终态，重大违约或合规要求，需审批 |

所有状态变更记录审计日志（操作人/时间/原因/附件）。

# 13 非功能需求

| 需求项 | 验收标准 |
|---|---|
| 列表页加载 | ≤ 2 秒（P95），含筛选和分页 |
| 详情页加载 | ≤ 2 秒（P95），含 Tab 切换 |
| 表单提交 | ≤ 3 秒（P95），含文件上传 |
| NIPR 校验 | 业务员提交触发异步校验，结果 ≤ 5 秒返回（超时转人工审核并提示） |
| 批量导入 | 1000 条数据 ≤ 5 分钟，支持异步进度查询 |
| 到期预警扫描 | 每日定时扫描协议到期日，扫描窗口内完成；通知发送成功率 ≥ 99% |
| 导出 | 5000 条数据导出 ≤ 30 秒 |
| 审计日志 | 所有 CRUD、状态变更、批量操作、合规相关事件均记录，不可删除，保留 ≥ 5 年 |
