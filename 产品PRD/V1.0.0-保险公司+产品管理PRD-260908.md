# 1 文档概述

## 1.1 目的

本文档详细描述海外保险数字化平台中"保险公司管理"模块下 **保险公司** 和 **产品管理** 两个子模块的全部页面、交互、字段、校验规则和业务逻辑，作为产品设计基线，指导后续 UI 设计、研发实施和测试验收。

## 1.2 范围

| 子模块 | 覆盖页面 |
|---|---|
| 保险公司 | 列表页、新增/编辑表单（5 步骤）、详情页（7 个 Tab）、批量导入（6 步骤）、重复检测、停用/启用弹窗、批量导出弹窗 |
| 产品管理 | 列表页、新增/编辑表单（5 步骤）、详情页（6 个 Tab）、产品状态管理弹窗 |

## 1.3 用户角色

| 角色 | 本模块权限 |
|---|---|
| 平台超级管理员 | 全部操作 |
| 保险公司运营 | 保险公司 CRUD、产品 CRUD、合作关系配置、批量导入导出、停用/启用 |
| 合规专员 | 查看保险公司/产品详情、合规文件、审计日志 |
| 佣金财务 | 查看结算配置、财务评级 |

## 1.4 核心术语

| 术语 | 定义 |
|---|---|
| Carrier | 保险公司，承担承保风险的主体 |
| NAIC Code | 全美保险监管官协会分配的唯一编码 |
| Admitted | 认可保险公司，持有州牌照 |
| Non-Admitted | 非认可保险公司（Surplus Lines），承保高风险业务 |
| AM Best | 最权威的保险公司信用评级机构 |
| LOB | Line of Business，业务线（Auto/Home/Life/Health 等） |
| Appointment | 保险公司在州监管层面对代理人的授权 |

# 2 保险公司子模块

## 2.1 保险公司列表页

> 原型参考：`InsurerList.tsx`

### 2.1.1 页面布局

页面从上到下依次为：**页头区** → **搜索筛选栏** → **批量操作栏**（选中时显示）→ **数据表格** → **分页**。最大宽度 1440px 居中。

### 2.1.2 页头区

| 元素 | 说明 |
|---|---|
| 标题 | "保险公司列表" |
| 副标题 | "共 X 家保险公司 · Y 条结果"（X 为总量，Y 为筛选后数量） |
| 操作按钮组（右对齐） | **重复检测**（btn-secondary）、**批量导入**（btn-secondary）、**导出**（btn-secondary）、**新增保险公司**（btn-primary） |

**交互：**
- 点击"重复检测"→ 跳转重复检测页
- 点击"批量导入"→ 跳转批量导入页
- 点击"导出"→ 打开批量导出弹窗
- 点击"新增保险公司"→ 跳转新增表单页

### 2.1.3 搜索筛选栏

卡片容器，内部水平排列，自动换行。

| 控件 | 类型 | 说明 |
|---|---|---|
| 搜索框 | 文本输入 | 占位符"搜索公司名、简称、NAIC编码…"，左侧 Search 图标，支持模糊匹配公司名称（name）、简称（shortName）、NAIC 编码（naicCode） |
| 公司类型 | 下拉选择 | 选项：全部 / Admitted / Non-Admitted |
| 合作状态 | 下拉选择 | 选项：全部 / 合作中（active）/ 待审核（pending）/ 已停用（inactive） |
| 大区 | 下拉选择 | 选项：全部 / Northeast / Southeast / Midwest / West |
| AM Best 评级 | 下拉选择 | 选项：全部 / A++ / A+ / A / A- / B+ |
| 重置按钮 | 文字按钮 | 红色文字 + XCircle 图标，仅当任意筛选条件不为默认值时显示，点击清空所有筛选 |

**交互：**
- 任一筛选条件变化时，自动重置到第 1 页
- 搜索为实时过滤（onChange 触发），无需按回车
- 所有筛选条件之间为 AND 关系

### 2.1.4 批量操作栏

仅当有选中项时显示，半透明浅蓝背景。

| 元素 | 说明 |
|---|---|
| 选中计数 | "已选 N 项"，蓝色加粗 |
| 批量启用 | 文字按钮，绿色 CheckCircle 图标 |
| 批量停用 | 文字按钮，红色 XCircle 图标 |
| 导出选中 | 文字按钮，Download 图标，打开批量导出弹窗 |
| 取消选择 | 文字按钮，右对齐（ml-auto），点击清空所有选中 |

### 2.1.5 数据表格

#### 表头列

| 列名 | 宽度 | 对齐 | 可排序 | 说明 |
|---|---|---|---|---|
| 复选框 | 40px | 居中 | 否 | 全选/全不选当前页 |
| 公司名称 | 自适应 | 左 | 是 | 双行显示：简称（加粗 13.5px）+ 全称（灰色 11.5px，超 28 字截断+…） |
| NAIC编码 | 固定 | 左 | 否 | 等宽字体，badge 背景 |
| 公司类型 | 固定 | 左 | 否 | badge 样式：Admitted（蓝色）/ Non-Admitted（橙色） |
| AM Best | 固定 | 左 | 否 | 彩色加粗文字，评级越高颜色越绿 |
| 总部大区 | 固定 | 左 | 否 | 文字显示 |
| 总保费 | 固定 | 右 | 是 | 货币格式化，等宽字体 |
| 保单数 | 固定 | 右 | 否 | 千分位格式化 |
| 赔付率 | 固定 | 右 | 是 | 百分比，颜色阈值：≤60% 绿色、60-65% 橙色、>65% 红色 |
| 续保率 | 固定 | 右 | 是 | 百分比格式化 |
| 结算方式 | 固定 | 左 | 否 | 如 Monthly / Quarterly |
| 合作状态 | 固定 | 左 | 否 | orb + label：合作中（绿）/ 已停用（灰）/ 待审核（黄） |
| 操作 | 80px | 居中 | 否 | 三个图标按钮 |

#### 排序交互

- 点击可排序列表头：当前列为排序列时切换升序/降序；非当前列时切换为该列降序
- 排序图标：当前列升序显示 ChevronUp，降序显示 ChevronDown，非当前列显示半透明 ChevronDown
- 默认排序：按总保费降序

#### 行操作按钮

| 按钮 | 图标 | 交互 |
|---|---|---|
| 查看详情 | Eye | 跳转保险公司详情页 |
| 编辑 | Edit2 | 跳转编辑表单页 |
| 更多 | MoreHorizontal → "更多"下拉菜单 | 包含停用/启用、删除选项 |

**行点击交互：** 点击表格行任意位置（复选框和操作按钮除外）跳转详情页。

**"更多"下拉菜单：**
- 使用 `position: fixed` + `getBoundingClientRect()` 定位，避免被表格 overflow 裁剪
- 点击外部区域关闭菜单
- 选项：
  - 合作中的公司 → 显示"停用"
  - 已停用的公司 → 显示"启用"
  - 删除（红色）→ 弹出删除确认对话框

**删除确认对话框：**
- 标题："确认删除"
- 副标题："此操作不可撤销"
- 红色警告框：显示公司全称
- 按钮：取消 / 确认删除（红色）
- 支持 overlay 点击关闭

### 2.1.6 分页

| 元素 | 说明 |
|---|---|
| 每页条数 | 10 条（可配置） |
| 页码导航 | 上一页 / 页码按钮 / 下一页 |

## 2.2 新增/编辑保险公司表单

> 原型参考：`InsurerForm.tsx`

### 2.2.1 页面布局

左侧为步骤导航栏（220px 固定宽度，sticky 定位），右侧为表单内容区。最大宽度 1000px 居中。

**页头：**
- 返回按钮（ArrowLeft）
- 标题：新增时为"新增保险公司"，编辑时为"编辑保险公司 — {公司名}"
- 副标题：新增时为"填写保险公司基本信息和配置"，编辑时为"修改保险公司信息，变更将记录至变更历史"

### 2.2.2 步骤导航栏

5 个步骤，每个步骤包含图标、名称和完成状态。

| 步骤 | 图标 | 名称 | 完成条件 |
|---|---|---|---|
| 0 | Building2 | 基本信息 | name && shortName && naicCode 非空 |
| 1 | MapPin | 监管信息 | type && state && region 非空 |
| 2 | Star | 财务评级 | amBest 非空 |
| 3 | DollarSign | 结算配置 | settlementCycle && billingFormat 非空 |
| 4 | FileText | 资质文件 | 3 个必传文件（营业执照/主合作协议/NDA）均已上传 |

**交互：**
- 当前步骤高亮蓝色背景，图标蓝色
- 已完成步骤显示绿色 CheckCircle，下方显示"已完成"
- 未完成步骤图标灰色
- 可点击任意步骤跳转（跳转时清除提交校验提示，见 2.2.9）
- 步骤导航栏底部**不显示**进度条与"X / 5 步完成"（已移除）

### 2.2.3 步骤 0：基本信息

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| 公司全称 | 文本输入 | 是 | 不可为空 | e.g. "Travelers Insurance Group" |
| 公司简称 | 文本输入 | 是 | 不可为空 | e.g. "Travelers" |
| NAIC 编码 | 文本输入 | 是 | 5 位数字 | 等宽字体，唯一性校验（仅比对未删除记录，已软删除的 NAIC 可复用） |
| 成立年份 | 数字输入 | 否 | 4 位年份 | e.g. 1853 |
| 官方网站 | URL 输入 | 否 | URL 格式 | e.g. www.travelers.com |
| 业务线 | 多选标签 | 是 | 至少选 1 个 | 13 个选项：Auto / Home / Life / Health / Commercial / Cyber / Travel / Professional / D&O / E&O / Marine / Specialty / Workers Comp |

**业务线多选交互：** 标签式多选，选中时蓝色背景+蓝色边框+CheckCircle 图标，未选中时灰色背景。

### 2.2.4 步骤 1：监管信息

| 字段 | 类型 | 必填 | 选项 | 说明 |
|---|---|---|---|---|
| 公司类型 | 单选卡片 | 是 | Admitted / Non-Admitted | Non-Admitted 选中时显示橙色提示框："Non-Admitted 保险公司需在 Surplus Lines 注册" |
| 合作类型 | 下拉选择 | 是 | 直接代理 / MGA / 批发经纪 / 推荐合作 / 聚合平台合作 | — |
| 总部州 | 下拉选择 | 是 | 美国 50 州 + DC | — |
| 大区 | 下拉选择 | 是 | Northeast / Southeast / Midwest / West | — |
| 城市 | 文本输入 | 否 | — | — |

### 2.2.5 步骤 2：财务评级

| 字段 | 类型 | 必填 | 选项 | 说明 |
|---|---|---|---|---|
| AM Best 评级 | 下拉选择 | 是 | A++ / A+ / A / A- / B++ / B+ / B / B- / C++ … / NR | 17 个等级 |
| AM Best 评级日期 | 日期选择 | 否 | — | — |
| S&P 评级 | 下拉选择 | 否 | AAA / AA+ / AA / AA- / A+ … / NR | 17 个等级 |
| S&P 评级日期 | 日期选择 | 否 | — | — |
| Moody's 评级 | 下拉选择 | 否 | Aaa / Aa1 / Aa2 … / NR | — |
| Moody's 评级日期 | 日期选择 | 否 | — | — |
| Fitch 评级 | 下拉选择 | 否 | AAA / AA+ / AA … / NR | — |
| Fitch 评级日期 | 日期选择 | 否 | — | — |

### 2.2.6 步骤 3：结算配置

| 字段 | 类型 | 必填 | 选项 | 默认值 |
|---|---|---|---|---|
| 结算周期 | 下拉选择 | 是 | Monthly / Quarterly / Semi-Annual / Annual | "请选择"（空值） |
| 账单格式 | 下拉选择 | 是 | API / CSV / Excel / EDI / Manual | "请选择"（空值） |
| 账单截止日 | 数字输入 | 否 | 1-28 | — |
| 付款期限 | 数字输入 | 否 | 天数 | — |
| 结算货币 | 下拉选择 | 否 | USD / EUR / GBP | USD |
| 保费归集方式 | 下拉选择 | 否 | 渠道代收转付 / 渠道直付 | — |

### 2.2.7 步骤 4：资质文件

文件列表，每项包含文件类型、上传按钮和状态。

**必须文件：**
| 文件类型 | 是否必传 | 接受格式 |
|---|---|---|
| 营业执照 | 是 | .pdf |
| 主合作协议 | 是 | .pdf |
| 保密协议（NDA） | 是 | .pdf |

**可选文件：**
| 文件类型 | 是否必传 | 接受格式 |
|---|---|---|
| 数据处理协议（DPA） | 否 | .pdf |
| 评级报告 | 否 | .pdf |

**每项交互：**
- 未上传：显示 FileText 图标 + "上传"按钮
- 已上传：显示绿色 CheckCircle + 文件名 + 文件大小 + "移除"按钮
- 支持在线预览：已上传文件显示 Eye 图标预览按钮，点击使用 iframe 打开 PDF
- 文件预览关闭时 revokeObjectURL 释放内存

### 2.2.8 底部操作按钮

底部导航位于**白色表单卡片内部**（卡片包裹至导航下方，导航上方有一条浅色分隔线）。

| 按钮 | 位置 | 样式 | 说明 |
|---|---|---|---|
| 上一步 | 左侧 | btn-secondary（白底） | ArrowLeft 图标；步骤 0 时禁用（灰色 opacity 0.4） |
| 步骤计数 | 中间 | 灰色文字 | "步骤 N / 5" |
| 下一步 | 右侧 | btn-primary（蓝底） | 文字 + ArrowRight 图标 |
| 提交/保存修改 | 右侧 | btn-primary（蓝底） | Send 图标；提交中显示"提交中..."并禁用 |

> 无"保存草稿"按钮（无草稿态）；提交按钮为蓝底而非绿色。

**提交成功：** 直接返回保险公司列表页并刷新列表（无独立成功页）。

### 2.2.9 提交校验与提示

点击"提交"时按步骤顺序校验必填字段，自动跳转到**第一个未填完的步骤**并红色标记该步骤缺失字段。

**逐步骤必填校验：**

| 步骤 | 校验的必填字段 | 缺失时提示文案 |
|---|---|---|
| 0 基本信息 | 公司全称、公司简称、NAIC 编码 | 请填写公司名称和 NAIC 编码 |
| 1 监管信息 | 总部州（类型/合作类型/大区有默认值） | 请填写总部信息 |
| 2 财务评级 | AM Best 评级 | 请填写财务评级 |
| 3 结算配置 | 结算周期、账单格式 | 请填写结算配置 |
| 4 资质文件 | 营业执照/主合作协议/NDA 三个必传文件 | 请上传资质文件 |

**红色标记：** 缺失字段显示红色边框 + 红色底纹，字段下方显示红色错误文字"此字段为必填项"；页面顶部同时显示该步骤对应的提示文案横幅。

**提示清除：** 用户点击"下一步""上一步"或步骤导航跳转其他步骤时，清除顶部提示横幅与字段红色标记。

**会话过期处理：** 提交时若 access token 过期（401），前端自动调用 /refresh 换新 token 并重试提交；refresh 请求自身不再触发二次刷新（防死锁）。若 refresh token 也过期则清除会话并跳转登录页，提交按钮不会卡在"提交中"。

# 5 状态流转

## 5.1 保险公司合作状态

```
pending（待审核） ──提交──→ active（合作中）
                                │
                          停用操作 │
                                ↓
                           inactive（已停用）
                                │
                          启用操作 │
                                ↓
                           active（合作中）
```

- 新增保险公司提交后进入 `pending` 状态，由管理员激活为 `active`
- 停用操作（需填写原因 + 确认）：`active` → `inactive`
- 启用操作（需填写原因 + 确认）：`inactive` → `active`
- 所有状态变更记录审计日志

## 5.2 产品状态

```
pending（待审核） ──提交──→ on-sale（在售）
                                │
                       ┌────下架操作────┐
                       ↓                ↓
                 off-sale（停售）    paused（暂停）
                       │                │
                    上架操作         上架操作
                       ↓                ↓
                    on-sale（在售）   on-sale（在售）
```

- 新产品提交后进入 `pending` 状态，由管理员激活为 `on-sale`
- 下架操作：`on-sale` → `off-sale`（需填写原因 + 影响确认）
- 暂停操作：`on-sale` → `paused`
- 上架操作：`off-sale` / `paused` → `on-sale`
