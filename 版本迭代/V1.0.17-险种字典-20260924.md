## 1. 迭代范围

**范围内：**
1. 字典四表迁移 + 播种（业务线 11 / 子险种 36 / 承保范围 9 / 关联 99）
2. 后端 dictionary 模块（管理端 CRUD + coverage-tree + 审计 + 缓存）
3. 集成侧 I4 字典快照接口 + I3 match 校验切换字典缓存（新增 `INVALID_COVERAGES_FOR_LOB`）
4. 前端「险种字典管理」页（系统管理菜单，3 Tab）+ i18n
5. 消费方切换：ProductForm、workos-simulator.html 删除硬编码副本
6. 集成接口文档增补（I4 + 新错误码）

**范围外（二期）：** 费率因子字典化、子险种×承保范围二级关联、审批流/版本化、渠道端复用。

## 5. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 存量产品 coverages 大小写混杂，切换字典后校验误伤 | 别名归一化层保留；T8 回归用例覆盖历史数据；停用/取消勾选不追溯存量（PRD §8.3） |

| match 新校验（INVALID_COVERAGES_FOR_LOB）影响已对接调用方 | I4 快照供其前置校验；接口文档提前增补并在发版公告注明；错误明细返回 invalid_coverages 便于排障 |
| 管理页取消勾选误操作 | 取消勾选展示引用产品数黄条提示；关联变更写审计可追溯 |
| 模拟器签名失败不可用 | 3s 超时降级只读快照并显式标注降级状态 |
