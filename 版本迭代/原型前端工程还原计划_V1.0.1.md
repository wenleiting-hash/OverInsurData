**UI 还原标准：** 100% 像素级完美还原设计原型

## 二、执行原则

### 2.1 UI 还原度标准
- **必须达到 100%** 与设计原型的视觉一致性
- 间距、颜色、字体大小、阴影、动画效果完全相同
- 响应式断点对齐，多分辨率适配

### 2.2 任务执行顺序
- **严格串行执行**：前一个 Phase 完成后才能开始下一个 Phase
- **不允许跳级或并行**：按 Phase 编号依次推进
- 每个 Phase 内部任务依次完成

### 2.3 验收机制
- **仅需一次最终验收**：整个计划全部完成后进行一次性验收
- **中间过程无需确认**：无需总结、无需暂停、无需阶段性汇报
- 验收通过后即可交付使用

### 2.4 实施范围限定
- ✅ **只做前端 UI 还原**：React 组件、Tailwind CSS 样式、路由导航、i18n 国际化、Mock 数据源
- ❌ **暂不碰后端/数据库**：不调用真实 API、不连数据库、不做认证鉴权、不集成第三方服务
- 🔄 **API Adapter 占位模式**：所有数据访问层返回 Mock 数据，标注 `todo: replace with real API later`，方便后期无缝替换
