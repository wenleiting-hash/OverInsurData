```bash
# Step 1: 启动 Redis Docker 容器
docker run -d -p 6379:6379 --name redis ai-saas-redis-dev

  imports: [

      host: process.env.REDIS_HOST || 'localhost',

  ],
```

**关键缓存场景**：

- ✅ **会话管理** → Refresh Token 黑名单（配合 PostgreSQL）

##### 3️⃣ JWT 正式实现（优先级：**中**）

**当前 Mock 实现问题**：
```typescript
// ❌ 非标准 Token 格式，无签名机制，易伪造
const accessToken = `AT-${shortId}-${timestamp}`.slice(0, 64);
```

**推荐修复路径**：
```bash
# Step 1: 安装 jose 库（Web Crypto API 兼容）
pnpm add jose

# Step 2: 实现标准 JWT 生成与验证
import { SignJWT, jwtVerify } from 'jose';

const secret = new TextEncoder().encode(process.env.JWT_SECRET);

// 生成 Access Token（短效 15 分钟）
const accessToken = await new SignJWT({ 
  user_id: user.ovwr_user_id,
  username: user.ovwr_username,
  role: user.role
})
  .setProtectedHeader({ alg: 'HS256' })
  .setIssuedAt()
  .setExpirationTime('15m')
  .sign(secret);

// 验证 Token
const { payload } = await jwtVerify(token, secret);
```

**支持 Host 集成模式**：
- RS256/JWS 签名（非对称加密）
- JWKS 端点验签（OIDC compatible）
- 标准 claims（sub, iat, exp, jti, iss, aud）

**迁移时间线**：
- **Phase 0-P0 Sprint**: Mock 实现维持运行（不影响 MVP 验证）
- **Phase 1 中期**: 替换为标准 JWT（上线前 1 个月）
- **Phase 2**: 支持 Host 平台 JWKs 验签（集成模式必需）

```tsx
import { useTranslation } from 'react-i18next';
import { useAuth } from '../contexts/AuthContext';
import apiClient from '../lib/api-client';

export function LanguageSwitcher() {
  const { t, i18n } = useTranslation();
  const { user } = useAuth();

  const changeLanguage = async (lng: string) => {
    // 1. 更新本地 i18n 实例
    await i18n.changeLanguage(lng);
    
    // 2. 保存到后端数据库（用户级别偏好）
    try {
      await apiClient.put('/users/preferences/current', {
        languageCode: lng,
      });
    } catch (error) {
      console.warn('Failed to save language preference:', error);
      // 降级：仅保存本地 localStorage
      localStorage.setItem('user_language', lng);
    }
  };

  return (
    <div className="relative group">
      <button className="px-3 py-1 rounded-lg bg-blue-50 text-blue-600 font-medium">
        {i18n.language === 'en-US' ? '🇺🇸 EN' : '🇨🇳 中文'}
      </button>
      
      {/* Dropdown Menu */}
      <div className="hidden group-hover:block absolute right-0 mt-2 w-32 bg-white shadow-lg rounded-lg divide-y divide-gray-100 z-50">
        <button 
          onClick={() => changeLanguage('en-US')}
          className="block w-full px-4 py-2 text-sm text-gray-700 hover:bg-gray-100"
        >
          English (US)
        </button>
        <button 
          onClick={() => changeLanguage('zh-CN')}
          className="block w-full px-4 py-2 text-sm text-gray-700 hover:bg-gray-100"
```

#### ✅ Day 10-11: 合规校验引擎缓存

**ComplianceCheckService 改造**:
```typescript
@Injectable()
export class ComplianceCheckService {
  private readonly cache = this.cacheManager.getClient();
  private readonly CACHE_KEY_PREFIX = 'compliance:';

  async checkNiprLicense(producerId: string, state: string): Promise<boolean> {
    const cacheKey = `${this.CACHE_KEY_PREFIX}nipr:${producerId}:${state}`;
    
    // 1. 尝试从缓存读取
    const cached = await this.cache.get<boolean>(cacheKey);
    if (cached !== undefined) {
      console.log(`[CACHE HIT] NIPR license for ${producerId}:${state}`);
      return cached;
    }
    
    // 2. 缓存 miss → 调用外部 API
    const result = await this.niprAdapter.checkLicense(producerId, state);
    
    // 3. 写入缓存（TTL: 24 小时）
    await this.cache.set(cacheKey, result, 86400);
    
    return result;
  }
}
```

**性能测试**:
- Before: ~1200ms（直接调用 NIPR API）
- After: ~300ms（缓存命中）
- Improvement: **75% 提升** ✅
