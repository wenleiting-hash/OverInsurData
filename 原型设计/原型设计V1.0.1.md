## A. 调整背景与原因

### A.1 调整背景

保险公司管理模块在 V1.0.0 中原定为"我司 ↔ 保司"双向协作模块，包含保司侧用户登录、API 对接、在线审批等设计。经业务确认，**上游保司均未开放 API，且无保司侧用户使用本系统**。因此 V1.0.1 对保险公司管理模块重新定位为：

> **我方纯内部管理模块** —— 所有保司相关数据（档案、产品、合作、账单、佣金率）均由我方运营人员人工录入或通过文件（CSV/Excel）导入；全域无审批流，采用"登记制 + 审计日志"模式。

### A.2 五项核心调整

| 序号 | 调整项 | 说明 |
|---|---|---|
| 1 | 状态双轨统一 | 原"档案状态（Active/Inactive）"与"合作状态（合作中/已终止）"双轨并存，现统一为单状态机，合作状态由合作记录驱动，避免歧义 |
| 2 | 审批口径统一 | 移除所有保司侧审批节点（如合同审批、产品上架审批），统一改为"登记即生效 + 审计日志留痕" |
| 3 | 枚举清理 | 清理依赖保司 API 或保司侧用户的枚举值（如保司审批状态、API 对接状态等），仅保留内部运营所需枚举 |
| 4 | KPI 无源移除 | 移除依赖保司实时 API 的 KPI 指标（实时保费、实时赔付等），详情页 KPI 收敛为 4 项可由账单/主数据计算的指标 |
| 5 | 新增结算比例主数据 | 新增 carrier_commission_rate 佣金率主数据管理，作为财务结算对账的期望值计算基准 |

## B. 功能清单及功能描述

> 本部分仅覆盖**上游保险公司管理**的 5 个子系统，渠道管理部分不在本文档范围内。
> 调整类型说明：**保留**（功能不变）、**降级**（功能简化或仅展示）、**隐藏**（UI 隐藏但数据保留）、**删除**（功能移除）、**新增**（V1.0.1 新增）。

### B.1 保险公司主数据管理

| 功能点 | 调整后描述 | 调整类型 | 原型交互调整 |
|---|---|---|---|
| 保险公司列表 | 展示保司档案列表，含基础信息与合作状态列 | 保留 | 新增"合作状态"列（来源：合作记录关联，无合作记录显示"未合作"） |
| 新增保险公司 | 表单录入保司基础信息（名称、NAIC Code、类型、评级等） | 保留 | 表单字段不变，移除"保司对接人登录账号"字段 |
| 编辑保险公司 | 修改保司档案信息 | 保留 | 操作后直接生效，无审批流；操作人、时间写入审计日志 |
| 保险公司详情 | 展示保司完整档案与关联信息 | 降级 | KPI 卡片由原 6 项改为 4 项：合作产品数、在合作状态、累计账单数、累计结算金额 |
| 导入保险公司 | 批量导入保司档案（CSV/Excel） | 保留 | 导入模板仅支持 CSV/Excel，新增数据校验提示（NAIC Code 重复等） |
| 导出保险公司 | 导出保司档案列表 | 保留 | 无调整 |
| 重复检测 | 基于 NAIC Code / 名称检测重复保司 | 保留 | 导入时自动检测，列表页提供"去重"操作入口 |
| 保司状态管理 | 保司档案启用/停用 | 保留 | 状态枚举收敛为 Active / Inactive；停用后关联产品自动下架 |
| 变更审计 | 保司档案所有变更记录 | 保留 | 展示操作人、时间、变更前后值，不可删除 |

### B.2 保险产品管理

| 功能点 | 调整后描述 | 调整类型 | 原型交互调整 |
|---|---|---|---|
| 产品列表 | 展示保司产品列表 | 保留 | 新增"所属保司"筛选；列表展示产品状态（上架/下架） |
| 新增产品 | 录入产品基础信息（名称、险种、可售州、费率方案等） | 保留 | 核保规则字段改为"文档化登记"（文本域 + 附件上传），不做规则引擎配置 |
| 编辑产品 | 修改产品信息 | 保留 | 操作直接生效，无审批流；审计日志记录 |
| 产品详情 | 展示产品完整配置 | 降级 | KPI 移除实时保费/赔付，改为：关联保司、可售州数、关联佣金率条数、累计账单行数 |
| 产品上下架 | 产品上架/下架操作 | 保留 | 下架后渠道侧不可见；操作直接生效，无审批 |
| 费率方案管理 | 配置产品在不同州的费率方案 | 保留 | 费率方案以"登记制"录入，不做自动报价计算 |
| 核保规则管理 | 核保规则登记 | 降级 | 由"规则引擎配置"降级为"文档化登记"（规则描述文本 + 附件），标注"自动执行待保司 API 开放" |
| 可售州管理 | 维护产品可售州列表 | 保留 | 多选州，支持按区域批量勾选 |
| 产品导入 | 批量导入产品（CSV/Excel） | 保留 | 导入模板仅 CSV/Excel，需关联已存在保司 |
| 产品导出 | 导出产品列表 | 保留 | 无调整 |

### B.3 我司与保险公司合作管理

| 功能点 | 调整后描述 | 调整类型 | 原型交互调整 |
|---|---|---|---|
| 合作关系列表 | 展示我司与保司的合作关系 | 保留 | 列表展示保司名称、合作状态、合同有效期 |
| 建立合作 | 新建合作关系，关联保司与合同 | 保留 | 操作直接生效，无审批流；合作状态自动设为"合作中" |
| 终止合作 | 终止与保司的合作关系 | 保留 | 终止后关联产品自动下架，佣金率置为失效 |
| 合作详情 | 展示合作关系完整信息 | 保留 | 新增"佣金率配置"面板，展示该合作下所有佣金率记录 |
| 合同管理 | 合同信息登记（合同编号、类型、有效期、附件） | 保留 | 合同以登记制录入，支持附件上传；无在线审批/签署流程 |
| 结算参数配置 | 配置合作结算参数（结算周期、币种等） | 保留 | 作为佣金率计算与对账的基础参数 |
| 产品资源接入 | 登记保司接入的产品资源 | 保留 | 关联产品管理模块的产品，无 API 自动同步 |

### B.4 保险公司财务与结算管理

| 功能点 | 调整后描述 | 调整类型 | 原型交互调整 |
|---|---|---|---|
| 账单导入 | 保司账单 CSV/Excel 导入 | 保留 | 账单格式仅支持 CSV/Excel；导入时校验列格式，失败行下载错误报告 |
| 账单解析 | 原"自动解析保司账单格式" | 删除 | 移除自动格式识别，改为固定模板导入（CSV/Excel） |
| 佣金率主数据管理 | 管理保司 × 险种/产品的佣金率（新增） | 新增 | 新增独立菜单，支持按保司/险种/产品维度配置佣金率、生效期、版本 |
| 对账管理 | 账单与佣金率试算值对账 | 保留 | 对账结果展示"账单值 / 试算值 / 差异"三列；差异行高亮 |
| 差异处理 | 处理对账差异 | 保留 | 差异处理直接登记处理结果与备注，无审批流 |
| 保费对账 | 保费金额对账 | 保留 | 展示试算值与账单值双列对比，支持校正值登记 |
| 结算单生成 | 生成结算单 | 保留 | 结算单数据来源为对账确认后的账单行 |

> **说明：** 功能点计数中，"账单解析"移除、"佣金率主数据管理"新增，净功能点数不变（仍为 6）。

### B.5 保险公司数据分析

| 功能点 | 调整后描述 | 调整类型 | 原型交互调整 |
|---|---|---|---|
| 业绩总览 | 保司维度业绩汇总 | 降级 | 仅展示账单口径数据（保费、佣金），移除实时指标 |
| 产品分析 | 保司产品维度分析 | 降级 | 仅展示账单中出现的产品维度统计 |
| 区域分析 | 按州/区域统计 | 降级 | 数据来源为账单行的州字段 |
| 渠道贡献 | 保司产品在各渠道的贡献 | 保留 | 数据来源为账单行关联的渠道信息 |
| 赔付率监控 | 赔付率指标 | 隐藏 | UI 隐藏，标注"待数据源（需保司账单扩展赔付字段）" |
| 续保率监控 | 续保率指标 | 隐藏 | UI 隐藏，标注"待数据源（需保司账单扩展续保字段）" |

### B.6 原型页面交互调整汇总

| 页面 | 关键调整 |
|---|---|
| 保险公司列表 | 新增"合作状态"列；无合作记录显示"未合作" |
| 保险公司详情 | KPI 由 6 项改为 4 项（合作产品数、合作状态、累计账单数、累计结算金额） |
| 产品表单 | 核保规则改为文档化登记（文本域 + 附件），标注"自动执行待保司 API 开放" |

| 账单导入 | 账单格式仅 CSV/Excel，固定模板 |
| 财务对账 | 展示"账单值 / 试算值 / 差异"三列；差异行高亮；支持校正值登记 |
| 佣金率管理（新增） | 按保司/险种/产品维度配置，含生效期、版本管理 |
| 数据分析页 | 赔付率/续保率卡片隐藏或标灰，提示"待数据源" |
