## 三、我司与保险公司合作管理

> **模块定位说明：** 本模块管理**我司（平台方）与上游保险公司**的合作关系：签约、合同、结算参数、对接人、续约、产品资源接入。
>
> **模块边界（2026-09-12 业务澄清后修订）：**
> - **上游合作（本模块 3.1–3.7）：** 我司 ↔ 保险公司 —— 合作建立/终止、合同协议、结算参数、对接人、续约、产品资源接入。
> - **中间授权（不属于本模块，归入渠道管理域 → 第十章）：** 保险公司授权我司的产品，由我司按渠道进行**产品销售授权、出单权限与限额配置**（原规划的 3.8/3.9 不再设立，内容以第十章 10.1/10.2 为准）。
> - **下游管理（渠道管理模块）：** 我司 ↔ 渠道合作商 —— 入驻、层级、佣金、绩效、培训、门户、产品授权、出单权限。
>
> 我司作为中间平台，从保险公司获取产品资源和出单权限，再授权给我司发展的渠道合作商使用。**合作记录与渠道授权不做强绑定、不做自动级联**：合作终止不自动收回渠道授权，渠道授权的配置/收回由第十章独立管理。

#### 3.6.1 合作状态机与流转条件（2026-09-13 明确）

**（1）状态定义**

| 状态 | 落库值 | 是否独立落库 | 含义 |
|---|---|---|---|
| 洽谈中 | Negotiating | 是（初始态） | 合作线索已建立，正在沟通合作类型、产品/区域范围、佣金等条款；新建合作向导完成后即进入此状态 |
| 待签约 | PendingSign | 是 | 核心条款已达成一致、合作意向已确认，等待合同签署 |
| 已签约 | Signed | 是 | 合同已签署归档，但合作生效日尚未到达（已填生效日且晚于当天） |
| 履行中 | Active | 是 | 合作在有效期内正常履行（生效日 ≤ 当天，且未到期/未终止） |
| 即将到期 | Expiring | 否（读时派生） | 履行中且距到期日 ≤ 90 天（列表/详情按到期日实时派生，不修改落库状态） |
| 已到期 | Expired | 否（读时派生） | 履行中且当天已超过到期日；续约后回到履行中，故不是终态 |
| 已终止 | Terminated | 是（终态） | 合作经终止操作结束（含立即/到期终止/指定日期终止），不可再流转、不可编辑关键字段 |

**（2）流转条件**

| # | 流转 | 触发动作 | 前置条件 | 执行方 | 可逆/说明 |
|---|---|---|---|---|---|
| 1 | — → 洽谈中 | 新建合作（三步向导保存） | 选定的保险公司不存在未终止的合作记录 | 有权限运营人员 | 初始态，不经过审批 |
| 2 | 洽谈中 → 待签约 | "推进待签约"（编辑保存） | 合作意向确认；合作类型、产品范围/区域等核心要素已填写 | 有权限运营人员 | 可逆（#3） |
| 3 | 待签约 → 洽谈中 | 退回洽谈（编辑保存） | 条款发生变化需重新洽谈 | 有权限运营人员 | 回退 |
| 4 | 待签约 → 已签约 | "签署合同"（编辑保存为已签约） | 合同已签署（3.3，可关联合同记录/附件）；合作生效日、到期日已填写 | 有权限运营人员 | 可逆（#5），签署即生效前可退回重签 |
| 5 | 已签约 → 待签约 | 退回待签约（编辑保存） | 合同签署作废/需重新用印 | 有权限运营人员 | 回退 |
| 6 | 已签约 → 履行中 | 到达合作生效日自动生效；或运营人员手动开始履行 | 生效日 ≤ 当天（自动）；手动推进无额外前置 | 系统定时任务 / 运营人员 | 不可逆（只能终止） |
| 7 | 履行中 → 即将到期 | 系统自动派生 | 到期日 - 今天 ≤ 90 天且 ≥ 0 天 | 系统（读时） | 仅展示派生，到期窗口外自动回到履行中 |
| 8 | 履行中/即将到期 → 已到期 | 系统自动派生 | 今天 > 到期日 | 系统（读时） | 非终态：续约后按 #9 回到履行中；也可按 #10 终止 |
| 9 | 已到期 → 履行中 | 续约执行（续约合同生效并更新到期日） | 续约决策完成、续约合同已签署、新到期日已填写 | 有权限运营人员 | 见续约操作；有效期重新计算 |
| 10 | 履行中/即将到期/已到期 → 已终止 | 终止合作（3.2） | 选择终止类型与生效方式（立即终止 / 到期终止 / 指定日期终止）并填写终止原因；**无需任何审批** | 有权限运营人员 | 终态：立即终止直接生效；未来生效由系统排期自动执行；终止后不可删除 |
| — | 任意非终态 → 其他状态 | — | 上表之外的跳转（如洽谈中直接到履行中、待签约直接终止等） | — | 一律拒绝（接口返回 400） |

**（3）权限与审计：** 上述运营动作要求操作人具备合作管理写权限（super_admin / ops_manager）；每次流转（含系统自动生效/自动终止）写入操作审计日志，记录操作人、前后状态、时间与原因。

#### 3.6.2 合作记录删除规则（2026-09-13 新增）

| 状态 | 是否允许删除 | 说明 |
|---|---|---|
| 洽谈中 | 允许 | 合作仅处于线索/洽谈阶段，无合同、结算与业务数据 |
| 待签约 | 允许 | 尚未签署、未产生业务数据 |
| 已签约 | 不允许 | 已有签署合同，需留存档案；如不再合作应走终止流程 |
| 履行中 / 即将到期 / 已到期 | 不允许 | 存在在途/历史业务与结算数据；退出合作走 3.2 终止，到期不续可自然到期或终止 |
| 已终止 | 不允许 | 终态档案保留，供审计与历史查询 |

- 删除为**软删除**（列表与详情不再可见，数据保留可审计），仅作删除标记并记录删除人与时间。
- 删除操作同样要求写权限并记录审计日志；对不允许删除的状态调用单条删除接口返回 400，前端不展示删除入口。
- **删除入口（对齐产品管理交互）**：
  - **单条删除**：列表操作列"更多"菜单或详情页"删除"按钮；
  - **批量删除**：列表首列勾选（仅洽谈中/待签约行可勾选，其余行复选框置灰）→ 批量操作条"批量删除"；后端对选中项逐条按状态校验，允许的删除、不允许的自动跳过，结果提示"已删除 N 条，M 条已跳过"；
  - **确认要求**：无论单条还是批量，点击删除后必须先弹出居中确认框（展示记录名称/数量与不可撤销提示），仅在确认回调内执行删除；取消不做任何变更。
- 已终止记录无法通过删除清除；如需物理清理走 DBA 数据治理流程，不在业务功能范围内。

#### 3.6.3 合作记录编辑权限（2026-09-13 新增）

| 状态 | 是否可编辑（合作基础信息） | 交互 |
|---|---|---|
| 洽谈中 / 待签约 / 已签约（生效日前） | 允许 | 新建合作关系在正式履行前可随时修改合作类型、期限、产品/区域范围、负责人等字段；状态字段仅可按 3.6.1 状态机选择合法下一状态 |
| 履行中 / 即将到期 / 已到期 | 不允许 | 列表"编辑"图标与详情页"编辑"按钮置灰不可点；后端对保存请求返回 400。退出合作走 3.2 终止，顺延期限走续约流程；合同/联系人/结算参数等子资源在各自 Tab 按其规则维护 |
| 已终止 | 不允许 | 终态只读，编辑入口置灰 |

### 3.7 保险公司产品资源获取与接入

**功能描述：** 我司从合作保险公司获取可销售的产品资源，完成产品在平台的接入建档（产品信息、费率档案、核保规则文档、可售州），使产品可被授权给下游渠道销售。这是中间授权链路的起点。【V1.0.1 调整】保留 5 步状态机作为建档进度跟踪，删除 API 测试与自动同步（上游无 API）。

| 操作名称 | 操作说明 |
|---|---|
| 步骤1：获取产品清单 | 从保险公司获取其可供平台销售的产品清单（手动录入 / 文件导入） |
| 步骤2：选择接入产品 | 从产品清单中选择要接入平台的产品 |
| 步骤3：录入产品基本信息 | 产品名称、代码、业务线、子险种、产品类型、保险期间 |
| 步骤4：配置产品可售州 | 登记该产品保司获批可销售的州列表及生效日期 |
| 步骤5：登记费率与核保档案 | 登记费率表档案（见 2.6）、核保规则文档（见 2.8）、产品文件 |
| 配置出单模式 | 平台直连出单 / 提交保险公司核保 / MGA独立核保 |
| 配置保单生成方式 | 平台生成电子保单 / 保险公司返回保单号和保单文件 |
| 配置批改/续保/退保流程 | 登记保单批改、续保、退保的流程说明（无 API 自动联动） |
| 配置理赔报案流程 | 登记理赔报案的流程说明（无 API 自动联动） |
| 配置产品文件 | 上传产品条款、费率手册、销售指南、核保手册等文件 |
| 配置产品培训材料 | 上传产品培训文档、视频（题库考试归渠道培训域） |
| 产品上架 | 产品接入建档完成后提交上架，产品状态变为"可授权" |
| 查看已接入产品列表 | 展示我司从各保险公司接入的所有产品及其状态 |
| 按保险公司筛选 | 查看指定保险公司接入的产品 |
| 产品接入进度跟踪 | 查看产品接入的当前阶段（5 步进度）和待办事项 |
| 产品下架 | 保险公司产品停售时，在平台下架并收回所有渠道授权 |
