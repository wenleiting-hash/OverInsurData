## A. 任务范围

### A.1 模块现状（设计基线）

保险公司管理模块当前形态（V1.0.2 原型直接以此为准，不包含任何合规功能页面）：

- 合规功能（OFAC 筛查、合规拦截、NIPR 牌照查询、牌照到期提醒、合规规则配置、合规审计报告）无页面、无入口，不在原型范围内。
- Appointment 模块为线下登记四件套：申请、状态跟踪、续期、终止。其中申请页含「申请 / 跟踪 / 续期」3 个 Tab。
- 侧边栏「合规管理」分组当前仅承载 Appointment 入口，**分组是否更名为「Appointment 管理」待确认**（见 B.7）。

### A.2 本期原型任务

本期原型设计仅一项主题：**财务对账流程**。账单导入以**导入批次（导入任务）**为核心对象：历次导入保留为可查询的任务列表（按月份/时间段），点击单个批次进入详情分析，并以批次为单位发起对账。业务流程：

```
保司定期导出对账单 → 我方导入（每次导入生成一个批次，历次批次可查）
→ 在批次详情按协议佣金率计算应得佣金 → 与该批保司账单逐笔对账
→ 一致：批次对账完成
  不一致：批次内显示异常数据 → 跟保司核实 → 人工处理（加备注 / 手动标记）→ 关闭 → 批次完成
```

两条硬约束：**原始数据不可重复导入、不可删除**。

## D. 交互规范

### D.1 原始数据保护

- 导入类数据（佣金账单、保费数据）禁止物理删除，仅可「作废标记」（软删）
- 作废数据默认列表隐藏，提供「查看已作废」筛选入口（仅管理员可见）
- 对账差异记录禁止删除，状态枚举：`open`（待处理）/ `suspended`（已挂起）/ `resolved`（已关闭）
- 差异备注只可追加，不可编辑或删除
- 所有操作（含作废、解锁对账）写入审计日志

### D.2 导入去重

- 去重键：`保司 + 账单月份 + 保单号`
- 重复行跳过，计入「跳过（重复）」，不计为导入失败
- 确认导入前预检并展示重复行数量

### D.3 批次与对账状态机

**导入批次状态（导入维度）：**

```
上传解析 → 预检待确认 → 导入完成（成功 / 部分失败 / 全部失败）→ 作废（软删，管理员）
```

**批次对账状态（对账维度，同一批次两种状态相互独立）：**

```
待对账 → 对账中 ──无差异──→ 对账完成（批次锁定）
            │
            └──有差异→ 差异处理中 ──全部关闭──→ 对账完成（批次锁定）
                                                       ↑
                                         主管「解锁对账」（审计留痕）
```

## E. 验收要点

1. 批次列表：进入账单模块首先看到历次导入任务列表，可按保司、账单月份、导入时间段、状态筛选；列表含行计数与对账状态标签；行无删除入口
2. 批次详情：点批次进入详情，展示概览指标、三值明细、重复/失败/异常页签；未对账批次可发起对账，已完成批次显示完成时间
3. 导入向导：预览阶段可看到重复行数量；导入结果分成功/失败/跳过计数，完成后跳转该批次详情
4. 对账视图：展示流程步骤条与当前批次阶段、试算取值分布；差异行高亮；可标记批次对账完成，完成后批次锁定，主管可解锁
5. 差异处理：差异带批次号，可从批次详情带筛选进入；可选择处理结果、追加多条备注、关闭 / 挂起；无删除按钮；备注保留时间线
6. 佣金率：财务模块存在独立「结算比例配置」页面，可维护按险种/产品/州分档费率、版本对比、Excel 导入、试算预览，页面展示四级取值优先级说明；合作详情仅展示只读摘要并可跳转该页（带入保司），合作侧无编辑入口
7. 全流程中账单原值始终只读，所有原始数据（批次、账单行、差异、备注）不可物理删除
