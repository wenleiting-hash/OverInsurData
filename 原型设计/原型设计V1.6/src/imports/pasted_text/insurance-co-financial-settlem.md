## 五、保险公司财务与结算管理

### 5.1 佣金账单导入批次管理

**功能描述：** 管理保险公司历次发送的佣金账单导入任务。每次上传确认后生成一个**导入批次（导入任务）**，系统保留全部历次批次形成列表，支持按保险公司、账单月份、时间段（导入时间起止）、批次状态筛选查询；点击单个批次进入**批次详情分析**，查看该批账单的导入概览、明细行、对账结果与差异。账单导入仅支持 CSV/Excel 格式（API拉取/EDI 置灰待开放）。【V1.0.2 约束】导入时自动去重（按保司 + 账单月份 + 保单号），同一账单不可重复导入；批次与原始账单数据**不可删除**（仅支持作废/软删标记，保留审计轨迹）。

### 5.3 佣金对账

**功能描述：** 【V1.0.1 调整】将系统基于佣金率试算的应付佣金与保险公司账单逐笔比对，标记差异。期望值来源升级为"佣金率试算 + 导入校正"（依据 5.7 结算比例配置主数据）。【V1.0.14 补充】佣金率支持州维度，逐笔试算按「产品+州 → 产品（全域）→ 险种+州 → 险种（全域）」四级回退匹配，均未配置时采用导入对账单原值。【V1.0.2 明确】完整对账流程为：① 保司导出对账单 → ② 我方导入生成导入批次（5.1）→ ③ 在批次详情中针对该批次按协议佣金率计算我方应得佣金 → ④ 与该批保司账单逐笔对账 → ⑤ 金额一致则批次对账完成 → ⑥ 不一致则标记为异常差异（5.4），跟保司核实后人工处理。对账以**导入批次**为运行单位，结果回写批次与对账行，不修改原始账单数据。

| 操作名称 | 操作说明 |
|---|---|
| 选择对账批次 | 从批次列表或批次详情选择一个待对账的导入批次发起对账（按保司+账单月份定位） |
| 期望值试算 | 系统依据 5.7 结算比例配置（佣金率主数据）对该批次明细逐笔试算应付佣金；按明细的产品代码与州字段四级回退取费率（产品+州 > 产品全域 > 险种+州 > 险种全域） |
| 导入校正 | 支持导入保司账单明细对试算期望值进行校正；未配置主数据费率的明细沿用导入对账单原值 |
| 逐笔比对 | 系统自动将试算/校正后的期望值与该批次账单金额逐笔比对 |
| 差异标记 | 金额不一致的记录标记为差异，展示差异金额和差异率 |
| 差异分类 | 自动识别差异类型（费率差异/保费差异/代理人不匹配/保单不存在） |
| 批次对账结果汇总 | 在批次详情展示对账结果：总行数、匹配行数、异常行数、账单金额/试算金额/差异金额合计 |
| 差异列表 | 展示该批次（或跨批次）差异记录，支持按批次、差异类型、金额筛选 |
| 差异详情 | 查看某条差异的系统试算明细与账单明细对比 |
| 批量确认差异 | 勾选多条差异记录批量确认处理方式 |
| 对账完成标记 | 该批次无差异或所有差异处理完毕后，标记该批次对账完成（批次锁定） |
| 解锁重新对账 | 对账完成后如需重对，由主管角色解锁批次（记录审计日志） |
| 生成对账报告 | 按批次生成对账总结报告（一致笔数/差异笔数/差异金额汇总） |
| 导出对账结果 | 将对账结果导出为Excel |
| 对账历史查询 | 查看历次对账运行记录（关联导入批次） |

### 5.4 差异处理

**功能描述：** 对对账发现的差异进行人工核查、调整。【V1.0.1 调整】追讨单/红字单作为独立实体延后实现，本版本仅做差异登记与调整，不生成追讨单/红字单。【V1.0.2 明确】差异处理为人工流程：跟保司核实后，通过加备注、手动标记处理结果等方式关闭差异。**原始账单数据与对账结果不可删除**，处理动作（备注、状态变更）独立记录在差异处理记录中，不修改原始导入数据。

| 操作名称 | 操作说明 |
|---|---|
| 差异核查 | 人工核查差异原因，查阅保单、合同、佣金方案 |
| 调整系统数据 | 确认系统计算有误时，生成佣金调整单修正（不修改原始账单数据） |
| 联系保险公司 | 确认保险公司账单有误时，记录并发起线下追讨/更正 |
| ~~追讨单生成~~ | 【V1.0.1 延后】追讨单作为独立实体延后实现，本版本仅登记追讨事项 |
| ~~追讨状态跟踪~~ | 【V1.0.1 延后】追讨状态跟踪随追讨单实体延后实现 |
| ~~红字调整~~ | 【V1.0.1 延后】红字单作为独立实体延后实现，本版本仅登记调整事项 |
| 差异备注 | 为每条差异添加处理备注和跟进记录（多次追加，保留时间线） |
| 手动处理标记 | 人工核实后标记处理结果（保司有误/我方计算有误/数据已更正/协商一致等） |
| 差异关闭 | 差异处理完成后标记为已解决，记录处理结果与处理人 |
| 差异挂起 | 暂时无法处理的差异标记为挂起，后续跟进 |
| 差异统计报表 | 按保险公司/差异类型/月份统计差异金额和处理率 |
| ~~删除差异记录~~ | 【V1.0.2 约束】差异记录不可删除，仅可关闭/挂起，保留完整处理轨迹 |

### 5.7 结算比例配置（V1.0.1 新增，V1.0.14 补充州维度）

**功能描述：** 【V1.0.1 新增】维护保司 ↔ 我方佣金率主数据，按险种/产品分档配置佣金率，支持生效期与版本管理，作为 5.3 佣金对账期望值试算的依据。【V1.0.14 补充】佣金率是合作协议（佣金补充协议，见 3.3）费率条款的**结构化登记镜像**，业务依据仍以协议为准；支持按州分档（州留空=全域适用）。州际销售策略与返佣差异由合作协议约定，运营据最新生效协议在此登记，对账时按「产品+州 → 产品全域 → 险种+州 → 险种全域」四级回退取值。

| 配置费率分档 | 按保费规模/保单年度等维度配置佣金率分档 |
| 设置首年佣金率 | 配置首年佣金比例(%) |
| 设置续年佣金率 | 配置第2年、第3年...第N年的续年佣金率（可递减） |
| 设置生效日期 | 佣金率方案的生效起始日期 |
| 设置失效日期 | 佣金率方案的失效日期（可选） |
| 版本管理 | 佣金率方案变更生成新版本，保留历史版本可查 |

| 导入佣金率方案 | 通过Excel批量导入佣金率配置 |

| 关联结算参数 | 与 3.4 结算参数配置中的佣金率字段关联 |
| 试算预览 | 输入模拟保费，预览佣金计算结果（仅用于校验配置，不触发实际结算） |
