## 1. 颜色系统

颜色令牌在 `src/index.css` 的 `@theme {}` 块中定义，通过 Tailwind CSS v4 的 `--color-*` 前缀全局可用。

### 1.1 品牌色（Primary & Secondary）

| Token | 值 | 用途 |
|---|---|---|
| `--color-primary` | `#0058BC` | 主品牌色，用于主按钮、激活状态、链接高亮 |
| `--color-primary-light` | `#0070EB` | 悬停、渐变终点 |
| `--color-primary-muted` | `#ADC6FF` | 低对比度强调，如弱化背景块 |
| `--color-secondary` | `#006687` | 次要品牌色，用于部分 KPI 图标色 |
| `--color-secondary-light` | `#60CDFF` | 用户头像渐变终点 |
| `--color-tertiary` | `#9E3D00` | 第三品牌色，用于特定 KPI 指标 |

### 1.2 曲面色（Surface）

| Token | 值 | 用途 |
|---|---|---|
| `--color-surface` | `#F9F9FF` | 页面基底色（与背景渐变配合） |
| `--color-surface-dim` | `#D8D9E5` | 最暗曲面，禁用状态背景 |
| `--color-surface-low` | `#F1F3FE` | 次低层曲面 |
| `--color-surface-container` | `#ECEDF9` | 容器/区域背景 |
| `--color-surface-high` | `#E6E8F3` | 提升曲面 |
| `--color-surface-highest` | `#E0E2ED` | 最高曲面层，用于悬浮元素底色 |

### 1.3 文字色（On-Surface）

| Token | 值 | 用途 |
|---|---|---|
| `--color-on-surface` | `#181C23` | 主文本（标题、正文） |
| `--color-on-surface-var` | `#414755` | 次要文本（描述、辅助信息） |
| `--color-outline` | `#717786` | 边框线、占位文字、弱化文字 |
| `--color-outline-var` | `#C1C6D7` | 轻量分隔线、输入框边框 |

在代码中，这些颜色常以内联常量对象 `C` 的形式在组件内部引用：

```typescript
// src/views/UserManagementView.tsx
const C = {
  text: '#181C23',      // --color-on-surface
  soft: '#414755',      // --color-on-surface-var
  muted: '#717786',     // --color-outline
  faint: '#A0A5B4',     // 介于 outline 和 outline-var 之间的弱化色
  border: 'rgba(193,198,215,0.42)',
  borderMid: 'rgba(193,198,215,0.58)',
  // ...
}
```

### 1.4 错误色

| Token | 值 | 用途 |
|---|---|---|
| `--color-error` | `#BA1A1A` | 错误文字、危险操作 |
| `--color-error-bg` | `#FFDAD6` | 错误提示背景 |

### 1.5 状态色

| Token | 值 | 含义 |
|---|---|---|
| `--color-status-action` | `#FF3B30` | 需立即操作（告警红）|
| `--color-status-running` | `#AF52DE` | 进行中（紫色）|
| `--color-status-active` | `#34C759` | 正常/活跃（绿色）|
| `--color-status-pending` | `#FFCC00` | 等待/待审（黄色）|

> **注意**：状态色直接映射到 Badge 和 Orb 组件的颜色变体。

## 2. 排版

### 2.1 字体族

```css
--font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'SF Pro Text', system-ui, sans-serif;
--font-mono: 'JetBrains Mono', 'SF Mono', ui-monospace, monospace;
```

- **Inter**：通过 Google Fonts 加载，字重范围 300–700，含斜体 400。用于全部 UI 文字。
- **JetBrains Mono**：字重 400/500/600，用于所有数字型数据（保费金额、编码、ID 等）。

### 2.2 字体平滑

```css
body {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

所有文字强制抗锯齿渲染，保证在 macOS/iOS 上的视觉一致性。

### 2.3 字号层级约定

| 用途 | 字号 | 字重 | 颜色 |

| 页面标题 | 通常 18–20px（Tailwind `text-lg`）| 700 | `#181C23` |
| 导航分组标签 | 11px | 600 | `#717786` |
| 导航项 | 13.5px | 500 | `#414755` |

## 4. 玻璃态曲面系统

InsureOS 的视觉语言以半透明玻璃态（Glassmorphism）为核心。所有曲面变量定义于 `:root`，CSS 类定义在全局样式中。

### 4.1 曲面变量

```css
:root {
  --glass-bg:          rgba(255, 255, 255, 0.68);  /* 标准玻璃背景 */
  --glass-bg-strong:   rgba(255, 255, 255, 0.82);  /* 强玻璃（更不透明）*/
  --glass-bg-light:    rgba(255, 255, 255, 0.45);  /* 轻玻璃（更透明）*/
  --glass-stroke:      rgba(255, 255, 255, 0.55);  /* 玻璃边框高光 */

  /* 标准阴影：蓝色调偏移 + 浅黑基础 */
  --glass-shadow: 0 2px 20px rgba(0, 58, 152, 0.07), 0 1px 3px rgba(0, 0, 0, 0.04);

  /* 提升阴影：用于悬停/激活状态 */
  --glass-shadow-elevated: 0 8px 32px rgba(0, 58, 152, 0.10), 0 2px 6px rgba(0, 0, 0, 0.05);
}
```

> 阴影使用品牌蓝（`#003A98`）调色，而非纯黑，强化品牌氛围。

### 4.2 曲面类

#### `.glass`（标准玻璃）

```css
.glass {
  background: var(--glass-bg);                          /* 68% 不透明白 */
  backdrop-filter: blur(32px) saturate(1.4);
  -webkit-backdrop-filter: blur(32px) saturate(1.4);
  border: 0.5px solid var(--glass-stroke);
  box-shadow: var(--glass-shadow);
}
```

**使用场景**：侧边栏 `<aside>`。

#### `.glass-strong`（强玻璃）

```css
.glass-strong {
  background: var(--glass-bg-strong);                   /* 82% 不透明白 */
  backdrop-filter: blur(40px) saturate(1.6);
  -webkit-backdrop-filter: blur(40px) saturate(1.6);
  border: 0.5px solid var(--glass-stroke);
  box-shadow: var(--glass-shadow-elevated);
}
```

**使用场景**：顶部导航栏（`<header class="glass-strong">`）、图表 Tooltip。

#### `.glass-light`（轻玻璃）

```css
.glass-light {
  background: var(--glass-bg-light);                    /* 45% 不透明白 */
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border: 0.5px solid rgba(255, 255, 255, 0.42);
}
```

**使用场景**：需要更高透明度的装饰性曲面。

#### `.glass-interactive`（可交互玻璃）

用于需要悬停反馈的玻璃态元素：

```css
.glass-interactive {
  transition: box-shadow 160ms ease, background 160ms ease, transform 120ms ease;
}
.glass-interactive:hover {
  background: rgba(255, 255, 255, 0.78);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.8), var(--glass-shadow-elevated);
  transform: scale(1.005);
}
```

悬停时的 `inset 0 1px 0 rgba(255,255,255,0.8)` 模拟玻璃顶部的镜面高光，`scale(1.005)` 提供微妙的浮起感。

### 4.3 曲面选用原则

| 层级 | 曲面类 | 典型用途 |
|---|---|---|
| 背景框架 | `.glass` | 侧边栏 |
| 前景框架 | `.glass-strong` | 顶栏、卡片、模态框 |
| 装饰元素 | `.glass-light` | 背景装饰层 |
| 交互元素 | `.glass-interactive` | 可点击卡片 |

## 5. 页面背景

```css
:root {
  --page-bg:
    radial-gradient(ellipse at 12% 20%, rgba(173, 198, 255, 0.32) 0%, transparent 48%),
    radial-gradient(ellipse at 88% 78%, rgba(196, 181, 253, 0.22) 0%, transparent 48%),
    radial-gradient(ellipse at 55% 50%, rgba(224, 234, 255, 0.4) 0%, #F9F9FF 100%);
}
```

三层径向渐变叠加：
- 左上角：蓝色光晕（`rgba(173,198,255,0.32)`）
- 右下角：紫色光晕（`rgba(196,181,253,0.22)`）
- 中心：蓝白渐变作为基底

效果是柔和的「极光」背景，与玻璃态组件协同营造深度感。

`html, body, #root` 均设置 `height: 100%; overflow: hidden`，整体布局不产生页面级滚动，滚动只发生在内容容器内部。

## 6. 组件规范

### 6.1 按钮

#### `.btn-primary`（主按钮）

```css
.btn-primary {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  padding: 9px 18px;
  background: #0058BC;
  color: #fff;
  border-radius: var(--radius-sm);   /* 8px */
  font-size: 13.5px;
  font-weight: 600;
  border: none;
  transition: background 140ms, box-shadow 140ms, transform 100ms;
}
```

| 状态 | 样式 |
|---|---|
| 默认 | `#0058BC` 背景，白色文字 |
| Hover | `#0049a0`，`box-shadow: 0 2px 8px rgba(0,88,188,0.28)`，`translateY(-0.5px)` |
| Active | `translateY(0)`（回弹） |

**用法示例：**
```jsx
<button className="btn-primary">
  <Plus size={14} />
  新增用户
</button>
```

#### `.btn-secondary`（次要按钮）

```css
.btn-secondary {
  padding: 8px 16px;
  background: rgba(255, 255, 255, 0.8);
  color: #181C23;
  border: 1px solid rgba(193, 198, 215, 0.9);
  border-radius: var(--radius-sm);
  font-size: 13.5px;
  font-weight: 500;
}
```

| 状态 | 样式 |
|---|---|
| 默认 | 半透明白底，灰色边框 |
| Hover | 纯白底，边框变为 `#0058BC`，文字变为 `#0058BC` |

#### `.btn-ghost`（幽灵按钮）

```css
.btn-ghost {
  padding: 7px 12px;
  background: transparent;
  color: #414755;
  border: none;
  font-size: 13px;
  font-weight: 500;
}
```

| 状态 | 样式 |
|---|---|
| 默认 | 透明背景 |
| Hover | `rgba(0,88,188,0.07)` 背景，文字变 `#0058BC` |

**典型用途**：面包屑链接、工具栏图标按钮（如通知铃铛）。

### 6.2 输入框与选择器

#### `.input-glass`

```css
.input-glass {
  background: rgba(255, 255, 255, 0.7);
  border: 1px solid rgba(193, 198, 215, 0.8);
```

| 状态 | 样式 |
|---|---|
| 默认 | 半透明白底，`rgba(193,198,215,0.8)` 边框 |
| Focus | 边框变 `#0058BC`，外发光 `0 0 0 3px rgba(0,88,188,0.12)` |
| Placeholder | 颜色 `#717786` |

**搜索框用法（带图标）：**
```jsx
<div className="relative">
  <Search
    size={14}
    style={{ position: 'absolute', left: 10, top: '50%', transform: 'translateY(-50%)', color: '#717786' }}

    type="text"
    placeholder="搜索..."
    className="input-glass"
    style={{ paddingLeft: 30, width: 230 }}
  />
</div>
```

#### `select.input-glass`（选择器）

在 `input-glass` 基础上追加：
```css
select.input-glass {

  background-image: url("data:image/svg+xml,..."); /* 内嵌 SVG 下拉箭头，颜色 #717786 */
  background-repeat: no-repeat;
  background-position: right 10px center;
  padding-right: 28px;
  cursor: pointer;
}
```

### 6.3 徽标 Badge

徽标是内联显示的状态标记，使用填充色背景 + 文字颜色配对。

**基础类：**
```css
.badge {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  padding: 3px 9px;
  border-radius: 999px;   /* 药丸形 */
  font-size: 12px;
  font-weight: 500;
}
```

**颜色变体：**

| 类名 | 背景 | 文字颜色 | 适用状态 |
|---|---|---|---|
| `.badge-blue` | `rgba(0,88,188,0.10)` | `#0058BC` | 信息、本地账号 |
| `.badge-green` | `rgba(52,199,89,0.12)` | `#1a7a2e` | 正常、活跃 |
| `.badge-yellow` | `rgba(255,204,0,0.15)` | `#7a5c00` | 待处理、等待 |
| `.badge-red` | `rgba(186,26,26,0.10)` | `#BA1A1A` | 错误、告警、锁定 |
| `.badge-gray` | `rgba(113,119,134,0.10)` | `#414755` | 停用、中性 |
| `.badge-purple` | `rgba(175,82,222,0.10)` | `#7a3ba8` | SSO、进行中 |
| `.badge-orange` | `rgba(255,149,0,0.12)` | `#a05800` | 警告、橙色状态 |

**导航角标（数字型）用法：**
```jsx
<span className="ml-auto badge badge-red" style={{ fontSize: 10, padding: '1px 6px' }}>3</span>
```

**带边框的状态 Badge（UserManagement 模式）：**

部分视图（如用户管理）使用带 `border` 的内联样式 Badge，比纯背景色 Badge 层次感更强：
```jsx
<span style={{
  display: 'inline-flex', alignItems: 'center', gap: 4,
  padding: '3px 8px', borderRadius: 999,
  fontSize: 11.5, fontWeight: 500,
  color: C.green, background: C.greenBg,
  border: `1px solid ${C.greenBorder}`,
}}>
  <UserCheck size={11} />
  正常
</span>
```

### 6.5 标签页 Tab Bar

```css
.tab-bar {
  display: flex;
  border-bottom: 1px solid #C1C6D7;  /* outline-var */
  gap: 0;
}

.tab-item {
  padding: 10px 18px;
  font-size: 13.5px;
  font-weight: 500;
  color: #414755;
  border-bottom: 2px solid transparent;
  transition: color 120ms, border-color 120ms;
  white-space: nowrap;
}

.tab-item:hover { color: #0058BC; }

.tab-item.active {
  color: #0058BC;
  border-bottom-color: #0058BC;   /* 2px 蓝色下划线 */
}
```

激活态通过 2px 下边框（而非背景色）来区分，是标准的下划线式标签页模式。

**用法示例：**
```jsx
<div className="tab-bar">
  {['概览', '保单列表', '佣金'].map(tab => (
    <div
      key={tab}
      className={`tab-item${activeTab === tab ? ' active' : ''}`}
      onClick={() => setActiveTab(tab)}
    >
      {tab}
    </div>
  ))}
</div>
```

### 6.6 数据表格

#### 基础用法

```jsx
<div className="table-scroll" style={{ '--sc': '120px' } as React.CSSProperties}>
  <table className="data-table">
    <thead>
      <tr>
        <th>姓名</th>
        <th>部门</th>
        <th>状态</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>张国强</td>
        <td>技术部</td>
        <td><span className="badge badge-green">正常</span></td>
      </tr>
    </tbody>
  </table>
</div>
```

#### 样式规则

**表格容器：**

## 8. 交互状态约定

### 8.1 过渡时长参考

| 类型 | 时长 | 缓动 |
|---|---|---|
| 颜色、背景切换 | 120–140ms | `ease` |
| 阴影提升 | 160ms | `ease` |
| 微小位移（hover 浮起）| 100–120ms | `ease` |
| 下拉弹出 | 140ms | `ease` |

### 8.2 Hover 模式

- **导航项**：背景淡入蓝色 7%，文字变主色
- **按钮**：主按钮变深色 + 阴影；次要按钮边框变主色；幽灵按钮背景淡入蓝色 7%

- **KPI 卡片**：`translateY(-1px)` + 阴影提升
- **Glass-interactive**：背景增浓 + 内嵌顶部高光 + `scale(1.005)`

### 8.3 Active（按下）模式

- **主按钮**：`translateY(0)` 回弹（抵消 hover 时的上移）

### 8.4 Focus 模式

- **输入框**：蓝色边框 + `0 0 0 3px rgba(0,88,188,0.12)` 外发光环（与 iOS/macOS 焦点环风格一致）

## 13. 国际化与多语言

项目通过 `src/i18n` 模块支持中文/英文双语。

```typescript
import { useLang } from '../i18n'
const { t, lang, setLang } = useLang()
```

- `t`：当前语言的翻译对象
- `lang`：`'zh'` | `'en'`
- `setLang(lang)`：切换语言

视图内部如需独立管理翻译（如 `UserManagementView`），使用本地 `T` 对象而不依赖全局 i18n：
```typescript
const T = { zh: { ... }, en: { ... } } as const
// 组件内通过 lang 索引获取
const tx = T[lang]
```

切换语言在 TopBar 的 `SettingsDropdown` 中完成，无需刷新页面。
