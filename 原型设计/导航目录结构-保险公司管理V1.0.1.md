### 关联产品 Tab 详细调整

**关联方式（A+B）：**

- **A 自动关联（主）**：产品在产品管理模块建档时选择「承保保司」，建立保司↔产品关联；保司详情自动聚合所有指向它的产品。
- **B 手动关联（补）**：保司详情提供「关联已有产品」按钮，弹出产品选择器（多选未关联到本保司的产品），用于历史数据补录。

**入口调整：**

| 入口 | 处置 | 说明 |
|---|---|---|
| 「新增产品」按钮 | ❌ 删除 | 产品主数据在产品管理模块创建，不在保司详情创建 |
| 编辑产品 | ❌ 删除 | 无编辑入口（只读视图） |
| 查看产品详情 | ✅ 保留 | Eye 图标，跳转产品详情页 |
| 「关联已有产品」按钮 | ➕ 新增 | 方案 B，仅用于历史数据补录关联 |

**表格列调整（8→8 列，赔付率→可售州）：**

| 列 | 调整 | 说明 |
|---|---|---|
| 产品名称 | 不变 | |

| 类型 | 不变 | |
| **可售州** | ➕ 新增 | 展示该产品获批的州列表（来源：产品可售州配置） |

调整后列：**产品名称 / 产品编码 / 险种 / 类型 / 可售州 / 保费 / 保单数 / 状态 / 操作**

## 4. 合规管理（Ch4 · 9 项）

**当前状态：** 侧边栏有 6 个合规叶子项（OFAC/拦截/牌照校验/到期提醒/规则/报告），Appointment 临时挂在渠道管理组（V1.0.12 决策）。

**V1.0.1 结构：** 合规管理作为二级可折叠分组，下设两个子组：

```
合规管理（二级分组）
├── Appointment管理
│   ├── 4.1 申请登记      → appointment-application
│   ├── 4.2 状态跟踪      → appointment-tracking
│   ├── 4.3 续期管理      → appointment-renewal
│   └── 4.4 终止管理      → appointment-termination
└── 合规管控
    ├── 4.5 NIPR牌照校验   → license-check
    ├── 4.6 牌照到期提醒   → license-expiry-reminder
    ├── 4.7 出单合规拦截   → compliance-interceptor
    ├── 4.8 合规规则       → compliance-rules
    ├── 4.8 合规报告       → compliance-report-generator
    └── 4.9 OFAC制裁筛查   → ofac-screening
```

| 导航层级 | 菜单项 | ViewId | 页面类型 | 功能清单对应 |
|---|---|---|---|---|
| **侧边栏二级分组** | 合规管理 | — | 可折叠父节点 | Ch4 整体 |
| └ 三级叶子 | Appointment申请 | `appointment-application` | 列表+登记表单 | 4.1 |
| └ 三级叶子 | Appointment状态跟踪 | `appointment-tracking` | 列表+时间线 | 4.2 |
| └ 三级叶子 | Appointment续期 | `appointment-renewal` | 列表+登记 | 4.3 |
| └ 三级叶子 | Appointment终止 | `appointment-termination` | 列表+登记 | 4.4 |
| └ 三级叶子 | NIPR牌照校验 | `license-check` | 列表+校验 | 4.5 |
| └ 三级叶子 | 牌照到期提醒 | `license-expiry-reminder` | 列表+提醒 | 4.6 |
| └ 三级叶子 | 出单合规拦截 | `compliance-interceptor` | 拦截日志列表 | 4.7 |
| └ 三级叶子 | 合规规则 | `compliance-rules` | 规则列表+CRUD | 4.8 合规规则 |

| └ 三级叶子 | OFAC筛查 | `ofac-screening` | 筛查列表+复核 | 4.9 |

### V1.0.1 调整要点

- Appointment 4.1–4.4 从渠道管理组移回保险公司管理组（V1.0.12 临时移至渠道组，前提是"保司 API 未开放前"；V1.0.1 确认永久无 API，回归合规域）
- 4.1–4.4 全部改为"线下办理 + 系统登记"，无审批（D2）
- 4.5 NIPR 牌照校验语义为"内部核验"（不假装外部成功）
