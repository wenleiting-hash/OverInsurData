# Testcase Gen（测试用例生成）

将 `产品需求/产品功能清单_V1.0.0.md` 的操作级功能点转换为结构化测试用例，与需求基线逐条对齐、可追溯。

## 输入识别

- 功能点编号/名称：`4.7 出单合规拦截`、`退保追回处理`
- 子模块名：`佣金计算与结算`（生成该子模块全量用例）
- 场景名：`场景三：佣金计算与结算`（按需求文档第五章业务场景）

**第一步**：在功能清单中定位章节，提取功能描述 + 操作清单表格 + 需求文档中对应的异常与边界描述（第五章各场景的"异常与边界"小节必须纳入用例来源）。

## 用例文档结构（输出模板）

```markdown
# {功能点编号} {功能点名称} 测试用例

| 元信息 | 值 |
|---|---|
| 需求来源 | 产品功能清单_V1.0.0.md § {章节} |
| 优先级 | P0 / P1 / P2（对齐需求文档第十一章） |
| 用例总数 | 正向 {n} / 反向 {n} / 边界 {n} |

## 用例明细

| 用例ID | 场景 | 前置条件 | 操作步骤 | 预期结果 | 类型 | 优先级 |
|---|---|---|---|---|---|---|
| {模块缩写}-{序号} | ... | ... | 1. ... 2. ... | ... | 正向/反向/边界 | P0 |
```

用例 ID 规则：模块缩写（如 APPT=Appointment、COMM=佣金、ONBD=入驻、AUTH=授权）+ 三位序号。

## 用例设计规则

### 逐操作覆盖
功能清单表格中的**每个操作至少 1 条正向用例**。重点操作补充反向/边界：

| 操作特征 | 必补用例 |
|---|---|
| 必填项表单（新增/编辑） | 必填为空、超长字符、特殊字符注入 |
| 停用/终止/下架 | 影响范围预览数据正确性、审批拦截、生效日期未来值 |
| 批量操作 | 空选择、部分失败、超大批量（性能边界） |
| 导入 | 模板下载、空文件、格式错误、重复值、校验失败行号反馈、部分成功 |
| 导出 | 空结果导出、大数据量异步导出、格式（xlsx/csv/pdf）正确性 |
| 审批类 | 通过/驳回/加签/转审/超时提醒/批量审批/撤销 |
| 到期提醒类 | 30/60/90 天边界值、当日到期、已过期 |
| 状态流转 | 每个合法流转 + 每个非法流转拦截 |
| 版本管理 | 版本对比差异高亮、回滚后数据一致性 |

### 权限矩阵用例
涉及角色的功能必须覆盖权限矩阵：平台管理员/保险公司运营/渠道运营/佣金财务/合规专员/机构管理员/团队长/代理人，验证：
- 功能权限：无权限角色不可见入口且接口返回 403
- 数据权限：代理人仅本人数据、团队长含下属、机构管理员全机构

### i18n 用例（每个页面级功能附加）
- 中英文切换后本页面全部文案正确、无 raw key
- 术语符合术语库（Carrier=保险公司 等）

## 专项场景模板

### 模板 A：8步出单合规校验
每条校验步骤生成一组用例，**8 步各独立验证 + 组合验证**：
```
| 步骤 | 正向（通过） | 反向（拦截） | 边界 |
| 1 持牌 | 该州持有效 P&C 牌照 | 未持牌/过期/吊销 | 牌照当日到期 |
| 2 代理人Appointment | ACTIVE | 未申请/被拒/已终止 | 状态切换当日 |
| 3 机构Appointment | ... | ... | ... |
| 4 产品可售州 | 州在 available_states | 不在列表 | 可售州移除当日 |
| 5 机构产品授权 | ... | ... | 授权到期日当天 |
| 6 代理人产品授权 | ... | ... | ... |
| 7 培训认证 | 认证有效期内 | 未完成/已过期 | 到期当日 |
| 8 出单限额 | 低于限额 | 超限转人工/拦截 | 恰好等于限额 |
```
补充用例：拦截原因展示与解决建议、拦截日志落库（含操作人/时间/产品/州/原因）、豁免审批与到期自动失效、8 步总耗时 ≤500ms（性能）。

### 模板 B：佣金计算引擎
```
1. 五阶段流水线：每阶段输入输出正确、阶段状态流转（待计算/计算中/完成/失败）
2. 规则匹配：多规则命中取权重最高（保险公司100/产品50/州30/业务线20/缴费10/档位5）；同分取最近更新；无匹配兜底
3. 佣金类型：直接/续期递减/阶梯（全额累进 vs 超额累进各算例）/Override 多级汇总/奖金/追回
4. 阶梯回溯：季末升档后回溯调整本季已结佣金
5. Override：计算基数（净保费/佣金/毛保费）、层级条件触发、叠加上限截断
6. 退保追回：区间比例表（0-3月100%等）、Pro-rata 按天、追回上限、抵扣不足结转、超结转期转坏账、豁免审批
7. 快照：计算期间层级调整不影响本期结果
8. 增量/全量：增量只算变更保单；全量重算后金额一致性
9. 失败恢复：失败自动重试3次、断点续算、手动重算幂等（作废后重写）
10. 性能：10万代理人/100万保单 ≤4 小时
```

### 模板 C：入驻流水线（7阶段）
```
阶段链：资料审核→NIPR校验→背景调查→合同签署→Appointment→账号开通→培训认证
1. 每阶段通过 → 进入下一阶段，进度条/时间线正确
2. 每阶段驳回 → 申请人可见原因、补充后重新提交
3. 同一申请累计驳回 3 次 → 第 4 次强制主管介入
4. NIPR：NPN 不存在/牌照过期 → 自动拦截
5. OFAC：未命中通过 / 疑似命中转人工复核 / 确认命中拒绝入驻
6. 合同签署：催签、撤销、签署完成归档
7. 账号开通：角色权限自动分配、MFA 首次绑定
8. 培训认证通过 → 出单权限自动解锁
```

### 模板 D：审批流
```
1. 提交 → 节点流转正确（主管→财务→总经理）
2. 驳回 → 退回修改，保留历史意见
3. 加签/转审 → 新审批人收到待办
4. 大额阈值 → 自动加签（如结算单金额 > 阈值）
5. 超时提醒 → 规定时间未审批触发通知
6. 撤销 → 审批前申请人可撤回
7. 并发：同一单据双人同时审批，仅一次生效
```

## 非功能用例（按需求第十章）

每个交付批次附加以下验证项（按需）：
- 页面加载 ≤2 秒（P95）、报表 ≤5 秒
- 批量导入 1 万条 ≤5 分钟，异步进度可查
- 审计日志：主数据变更字段前后值完整、日志不可删除
- 敏感数据脱敏（SSN 仅后 4 位）、传输加密
- 会话超时（后台 30 分钟/门户 2 小时）

## 交付物

输出用例文档（默认保存到 `测试用例/` 目录，文件名 `{功能点编号}_{功能点名称}_测试用例.md`，目录不存在则创建），并汇报：用例总数与类型分布、需求覆盖率（操作清单逐条映射表）、识别出的需求疑问点（若有，需产品确认）。
