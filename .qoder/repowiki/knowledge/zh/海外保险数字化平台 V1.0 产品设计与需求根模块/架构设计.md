本模块由两个并列子目录构成：`产品需求/` 存放 V1.0.0 版本的功能清单与需求文档，定义保险公司管理与渠道管理的业务边界；`产品设计/UI-V1.0/` 是基于 React + Vite 的前端原型，通过 `App.tsx` 中的 `ViewId` 路由表（dashboard、insurer-list/detail/new/edit/import/duplicate、product-list/detail/new/edit、cooperation、finance、insurer-analytics、channel-list/appointment/hierarchy/onboarding/master）将各 `views/` 页面挂载到统一的 Sidebar/TopBar 布局中，并以 `data/mockData.ts` 及按业务域划分的 mock 数据文件（appointment、channel、cooperation、finance、insurer*、onboarding、product）作为无后端的数据源。需求文档与 UI 原型的映射关系体现在：每个需求条目对应一个 `views/` 下的页面组件与一组 mock 数据，二者共同构成 V1.0 的“需求→原型”可验证闭环。
