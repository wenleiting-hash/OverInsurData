## 四、Tailwind v4 配置说明

真实工程使用 **PostCSS 方式**（`@tailwindcss/postcss`），原型使用 **Vite 插件方式**（`@tailwindcss/vite`）。两者等价，不需要切换：

```js
// postcss.config.cjs — 真实工程（已正确）
module.exports = {
  plugins: { '@tailwindcss/postcss': {}, autoprefixer: {} },
};
```

index.css 中 `@import 'tailwindcss'` + `@theme {}` 定义设计令牌，与原型一致。

### Step 2: 安装 & 验证

```bash
cd insurance-platform
pnpm install
pnpm --filter web-carrier-admin run dev
```

**验证要点**：
- [ ] TypeScript 编译无新增错误（strict 暂关）
- [ ] lucide-react 图标导入正常（⚠️ 可能有 breaking change）
- [ ] Tailwind 类生效（glass / flex / gap 等）
- [ ] i18next 初始化无报错

### Step 3: 失败回滚预案

| 场景 | 应对 |
|---|---|
| lucide-react 升级后图标找不到 | 查 1.x 迁移指南，批量替换 import |
| Router v7 API 变化 | 当前只用 BrowserRouter 外壳，改成本极低 |
| Vite 8 + Tailwind v4 不兼容 | 降级回 Vite 5，保留其他升级 |
