# 数据库设计方案 V2.1（PostgreSQL 15 + Drizzle ORM）
## 修订版本：2026-09-02 - 新增多语言管理和权限管理模块完整设计

---

## 一、数据库平台选型（融合版）

### 1.1 核心决策：PostgreSQL 15 + Drizzle ORM

**选择理由:**
- ✅ **统一管理与部署**: 符合用户决策，降低运维复杂度
- ✅ **JSONB 灵活存储**: 支持渠道产品授权限额配置（bind_limits/permissions）、权限模板 JSON/YAML 存储、翻译词条扩展字段等复杂结构
- ✅ **Drizzle ORM 类型安全**: Schema 定义与代码同构，自动生成 DDL 迁移脚本
- ✅ **全文检索强**: TsVector+TsQuery 内置，无需额外插件即可实现合规日志检索、审计日志查询
- ✅ **云厂商兼容**: AWS RDS PG / Google Cloud SQL / Azure Database 均支持
- ✅ **Java/NestJS 生态无问题**: HikariCP + Drizzle 组合成熟稳定

### 2.2 物理部署策略

| 阶段 | 方案 | 说明 |
|---|---|---|
| **Phase 1(初始)** | 单实例 4 个 schema 隔离 | `carrier_db`/`channel_db`/`auth_db`/`i18n_db`,成本最低，运维简单 |
| **Phase 2(增长)** | 读写分离 (1 主 2 从) | 主写从读，报表走从库，i18n 库只读从高可用副本 |
| **Phase 3(规模化)** | 按域拆分独立实例 | auth+i18n 共置，commission 独立，carrier/channel 独立 |

## 四、i18n_db: 多语言管理域（全新设计） ⭐新增

### 4.1 auth_i18n_translation (翻译词条表 - 核心表)

```typescript
import { pgTable, varchar, timestamp, index, jsonb, integer } from 'drizzle-orm/pg-core';

export const authI18nTranslation = pgTable('auth_i18n_translation', {
  translationId: varchar('translation_id', { length: 32 }).primaryKey(),
  namespace: varchar('namespace', { length: 64 }).notNull(), // common/carrier/channel/compliance/permission...
  key: varchar('key', { length: 256 }).notNull(),
  enUS: varchar('en_us', { length: 512 }).notNull(),
  zhCN: varchar('zh_cn', { length: 512 }),
  type: varchar('type', { 
    enum: ['label', 'button', 'placeholder', 'toast', 'confirm', 'validate', 'error-page'] 
  }),
  module: varchar('module', { length: 32 }),  // 如：channel/carrier/commission
  section: varchar('section', { length: 64 }), // 如：页面标题/表单字段/操作按钮
  status: varchar('status', { length: 1 }).default('1'), // 1=已确认发布 0=待审核草稿
  modified: integer('modified').default(0), // 是否已修改但未发布
  reviewedBy: varchar('reviewed_by', { length: 32 }), // 审核人 ID
  reviewedAt: timestamp('reviewed_at'),
  metadata: jsonb('metadata').$type<{
    originalSource?: string; // 原始来源 (如 Figma URL)
    lastEditor?: string;     // 最后编辑人
    editHistory?: Array<{    // 编辑历史（最近 5 次）
      editedBy: string;
      editedAt: string;
      beforeEn: string;
      afterEn: string;
      beforeZh: string;
      afterZh: string;
    }>
  }>(),
  createdAt: timestamp('created_at').defaultNow().notNull(),
  updatedAt: timestamp('updated_at').defaultNow().notNull(),
}, (table) => ({
  uniqueKey: index('uk_namespace_key')
    .on(table.namespace, table.key),
  idxNamespace: index('idx_namespace').on(table.namespace),
  idxStatus: index('idx_status').on(table.status),
}));
```

**对应 DDL:**
```sql
CREATE TABLE auth_i18n_translation (
  translation_id VARCHAR(32) PRIMARY KEY,
  namespace VARCHAR(64) NOT NULL,
  key VARCHAR(256) NOT NULL,
  en_us VARCHAR(512) NOT NULL,
  zh_cn VARCHAR(512),
  type VARCHAR(32) CHECK (type IN ('label', 'button', 'placeholder', 'toast', 'confirm', 'validate', 'error-page')),
  module VARCHAR(32),
  section VARCHAR(64),
  status VARCHAR(1) DEFAULT '1' CHECK (status IN ('0', '1')),
  modified INTEGER DEFAULT 0,
  reviewed_by VARCHAR(32),
  reviewed_at TIMESTAMP WITH TIME ZONE,
  metadata JSONB,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,
  CONSTRAINT uk_namespace_key UNIQUE (namespace, key)
);

CREATE INDEX idx_namespace ON auth_i18n_translation(namespace);
CREATE INDEX idx_status ON auth_i18n_translation(status);
```

**业务规则:**
- ✅ 同一 namespace + key 不允许重复
- ✅ zhCN 可空（未翻译），但 enUS 必填
- ✅ status=0 表示草稿状态（未发布），status=1 表示已发布至生产环境
- ✅ modified=1 表示有未发布的修改
