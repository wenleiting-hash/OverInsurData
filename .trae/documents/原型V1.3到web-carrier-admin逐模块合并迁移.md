# 原型V1.3 → web-carrier-admin 逐模块合并迁移方案

## Context（背景与目标）

原型工程 `产品方案/设计原型V1.3/src` 近期完成了多项重要改动（渠道管理交互增强、登录页独立语言切换、Dashboard 像素级修复、英文环境中文清零、i18n 模块化架构、保险公司模块 i18n 改造）。这些改动目前只存在于原型工程，需要同步到正式工程 `insurance-platform/apps/web-carrier-admin`。

**关键发现：目标工程非空脚手架。** 目标已有 94 个视图、16 个 i18next 命名空间（含独立 insurer-form.json）、components/ui/ 组件库抽象，已采用 V2.0 技术栈（i18next + Tailwind class + glass-strong）。原型仅 30 个视图、用自定义 Context + 内联 style。整体覆盖会倒退技术栈并丢失目标独有的 64+ 个页面。

**决策：逐模块对比合并。** 保留目标 V2.0 架构，把原型近期价值适配后同步过去。不可倒退目标技术栈（project_memory 要求对齐 V2.0 方案）。

## 工程差异速查

| 维度 | 原型V1.3 | 目标 web-carrier-admin |
|------|---------|------------------------|
| 视图数 | 30 | 94 |
| i18n | 自定义 Context（useLang/t.xxx） | i18next + react-i18next（useTranslation/t('xxx')） |
| locales | 模块化 ts 字典 5 个 | JSON 命名空间 16 个（zh-CN + en-US 各一份） |
| 样式 | 内联 style 为主 | Tailwind class + glass-strong + ui/ 抽象 |
| 数据 schema | mockData.ts（id/name/founded number） | mockInsurerData.ts（carrierId/carrierName/establishedDate string） |
| 路由 | switch(currentView) | switch(currentView)（同模式，保留目标） |
| tsconfig strict | true | false（不在合并期间改） |

## 合并批次与依赖

```
B0(i18n 键基座) ──┬─→ B1(渠道，依赖 channel.json 键)
                  ├─→ B2(insurer，依赖 insurer.json + modals 键)
                  ├─→ B3(Dashboard，依赖 dashboard.json)
                  ├─→ B4(Login，需新建 login namespace)
                  ├─→ B5(产品，依赖 product.json)
                  └─→ B6(合作/财务/分析)
                       ↓
                    B7(框架壳收尾)
```

B0 是硬前置；B1 最优先（近期改动密度最高）；B7 收尾。不允许跳级。

## B0 — i18n 键值基座对齐（无视图改动，仅补 JSON 键）

**目标：** 把原型模块化字典的新增键补到目标 16 个 JSON，让后续批次 t('xxx') 不返回裸键。

**对比文件：**
- 原型 `i18n/core.ts` ↔ 目标 `common.json` + `dashboard.json`
- 原型 `i18n/insurer.ts` ↔ 目标 `insurer.json` + `insurer-form.json`
- 原型 `i18n/product.ts` ↔ 目标 `product.json`
- 原型 `i18n/coop.ts` ↔ 目标 `cooperation.json` + `finance.json` + `analytics.json`
- 原型 `i18n/compliance.ts` ↔ 目标 `compliance.json` + `appointment.json`

**键映射规则：**
| 原型字典 | 键前缀 | 目标命名空间 | 备注 |
|----------|--------|--------------|------|
| core.ts | brand/topbar/sidebar/settings | common | |
| core.ts | dashboard.* | dashboard | |
| insurer.ts | ins* | insurer | 去前缀转嵌套 |
| insurer.ts | dm*/bem* | insurer → modals.disable.*/modals.batchExport.* | |
| product.ts | prd/psm | product → modals.statusModal.* | |
| coop.ts | coop/fin/an | cooperation/finance/analytics | |
| compliance.ts | apt | compliance/appointment | |

**转换规则：**
- 原型 `t.insListTitle`（点访问） → 目标 `t('listTitle')`（函数调用）
- 原型 `insPager(n,p,t)` 函数式 → i18next 插值 `t('pager.summary', { total: n, page: p, totalPages: t })`
- 原型 `{en ? 'X' : 'Y'}` 三元 → 写入 zh/en JSON 成对键，改用 `t('key')`
- 原型 `Record<string,{zh,en}>` 内联枚举 → `Record<string,{labelKey}>` + `t(labelKey)`

**约束：** zh 文案必须与原型 byte-identical；新增 namespace 必须在 config.ts 注册。

**验证：** 切换 EN/ZH，所有 t() 返回翻译文本而非裸键。

## 数据 schema 合并规则（适用于所有批次）

**关键：schema 不兼容，不可直接拷贝。**

| 维度 | 原型 | 目标 |
|------|------|------|
| 主键 | id: '1' | carrierId: 'c1001' |
| 名称 | name + shortName | carrierName + shortName |
| 成立 | founded: 1996 (number) | establishedDate: '1996-08-26' (string) |

**规则：**
1. 保留目标 schema（94 视图已基于此，不可倒退）
2. 原型增量字段（commissionIncome/channelCount 等）补到目标接口 optional 字段（? 可空）
3. 原型独有数据文件 → 新建目标对应 mock 文件（加 mock 前缀，按目标 schema 规范化）
4. 数据中文：枚举标签 → labelKey + t()；自由文本 → 平行 xxxEn 字段，视图用 lang === 'en' 切换
