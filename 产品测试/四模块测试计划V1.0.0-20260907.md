## 一、测试策略总览

### 1.1 测试范围

| 模块 | 页面路由 | 前端组件 | 后端 Controller | API 端点数 |
|------|----------|---------|-----------------|-----------|
| **用户管理** | `/permission/users` | `UserListView.tsx` | `user.controller.ts` | 8 |
| **部门管理** | `/department-management` | `DepartmentView.tsx` | `department.controller.ts` | 6 |
| **权限管理** | `/permission-management` | `PermissionView.tsx` | `role.controller.ts` | 5 |
| **多语言管理** | `/i18n-management` | `I18nManagementView.tsx` | i18n API (hooks) | 4 |

### 1.2 测试类型

| 类型 | 说明 | 覆盖方式 |
|------|------|---------|
| **API 测试** | 后端 REST 端点的请求/响应验证 | PowerShell 脚本 / cURL |
| **功能测试** | 前端页面各功能点的端到端验证 | 浏览器手工验证 |
| **边界测试** | 异常输入、权限不足、数据不存在等边界条件 | API 脚本 + 浏览器 |
| **数据一致性** | CRUD 操作后数据库实际状态验证 | SQL 查询 |

### 1.3 测试账号

| 账号 | 密码 | 角色 | 用途 |
|------|------|------|------|
| `admin` | `admin123` | `super_admin` | 主测试账号，验证全部功能 |
| 其他已创建用户 | — | 不同角色 | 验证角色权限差异 |

### 1.4 公共前置步骤

所有 API 测试均需先获取 JWT Token：

```powershell
$loginResp = Invoke-RestMethod -Uri "http://localhost:3001/api/auth/login" `
  -Method POST -ContentType "application/json" `
  -Body '{"username":"admin","password":"admin123"}'
$token = $loginResp.data.accessToken
$headers = @{ Authorization = "Bearer $token" }
```
