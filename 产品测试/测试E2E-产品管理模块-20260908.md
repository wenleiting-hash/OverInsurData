## 三、发现的 Bug

### 🔴 Bug-1: 产品新建/编辑不持久化（P0）

| 项 | 内容 |
|---|---|
| **严重程度** | 严重 |
| **页面** | 新增产品 / 编辑产品 |
| **现象** | "保存草稿"按钮仅更新客户端状态，未调用后端 API（POST/PUT），刷新页面后数据丢失 |
| **根因** | 产品表单的保存逻辑可能仅做了前端状态管理，未集成 `productApi.create()` / `productApi.update()` 调用 |
| **影响** | 产品 CRUD 核心功能不可用 |

### 🔴 Bug-2: 产品详情页数据加载失败（P0）

| 项 | 内容 |
|---|---|
| **严重程度** | 严重 |
| **页面** | 产品详情页 |
| **现象** | 产品名称显示 "Loading..."，类型显示 `values.typeundefined`，核保模式显示 `values.underwritingundefined`，上架时间显示 `已上线 NaN 月` |
| **根因** | 后端 API 返回的字段名与前端取值的字段名不匹配，或 API 响应结构变更但前端未适配 |

### 🔴 Bug-3: 编辑表单数据未预填（P0）

| 项 | 内容 |
|---|---|
| **严重程度** | 严重 |
| **页面** | 编辑产品表单 |
| **现象** | 进入编辑模式时所有字段为空，页面标题显示"编辑 ·"（缺少产品名）|
| **根因** | React 表单 useState 初始化仅首次渲染生效，异步 API 数据到达后未通过 useEffect 更新表单状态（已知的 React 异步数据加载陷阱）|

### 🟡 Bug-4: i18n 键值缺失

| 项 | 内容 |
|---|---|
| **严重程度** | 中 |
| **页面** | 产品详情页 |
| **现象** | 显示 `values.typeundefined`、`values.underwritingundefined` 等原始键值 |
| **根因** | i18n 翻译文件中缺少 `values.type` 和 `values.underwriting` 区段的键定义 |

### 🟡 Bug-5: 保险公司下拉框空白选项

| 项 | 内容 |
|---|---|
| **严重程度** | 中 |
| **页面** | 产品列表页 - 筛选器 |
| **现象** | "保险公司" 下拉筛选框中存在一个空白选项（无文字、无值）|
| **根因** | 筛选器数据源中包含空值或 undefined 的保险公司名称 |

### 🟡 Bug-6: 本年保费排序为字符串排序

| 项 | 内容 |
|---|---|
| **严重程度** | 中 |
| **页面** | 产品列表页 - 排序 |
| **现象** | 点击"本年保费"列头排序后，数据顺序为字符串排序（如 11.2M, 12.5M, 2.1M）而非数值排序 |
| **根因** | 后端排序将 revenue/premium 字段当字符串处理，或前端传入的 sortKey 映射到了非数值列 |

### 🟡 Bug-7: 编辑页标题缺少产品名

| 项 | 内容 |
|---|---|
| **严重程度** | 低 |
| **页面** | 编辑产品表单 |
| **现象** | 面包屑和标题显示"编辑 ·"，缺少产品名称 |
| **根因** | 编辑模式下产品数据未加载完成时，标题模板使用了 undefined 值 |

### 🟡 Bug-8: 创建产品 Step5 文件上传为必传

| 项 | 内容 |
|---|---|
| **严重程度** | 低 |
| **页面** | 新增产品 - Step 5 |
| **现象** | "提交上架申请"要求上传所有必传文件（产品备案表/费率文件/产品指南），否则无法提交 |
| **建议** | 考虑支持"先提交基础信息 + 后补文件"的流程，降低使用门槛 |

## 五、结论与建议

### 总体评价

| 子模块 | 评价 | 说明 |
|--------|------|------|
| **产品列表页** | ⭐⭐⭐⭐ 良好 | 搜索/筛选/排序/分页基本完善，2 个小 Bug |
| **新增产品** | ⭐⭐ 可用 | 5 步向导表单 UI 完整，但**提交不持久化** |
| **产品详情页** | ⭐ 不可用 | 数据加载失败，多处显示 undefined |
| **编辑产品** | ⭐ 不可用 | 数据未回显，保存不持久化 |
| **产品授权** | ⭐⭐⭐⭐⭐ 优秀 | 功能完整，筛选/详情/新增授权均正常 |

### 优先修复建议

1. **P0-1**: 产品创建/编辑 API 集成 — 保存草稿和提交需调用后端 POST/PUT 接口持久化
2. **P0-2**: 产品详情页数据映射修复 — 排查后端返回字段名与前端取值字段名的对应关系
3. **P0-3**: 编辑表单数据回显 — 添加 useEffect 监听异步 API 数据到达后更新表单状态
4. **P1**: 修复 i18n 缺失键（values.type / values.underwriting 区段）
5. **P2**: 修复保险公司下拉空白选项 + 保费排序改为数值排序
