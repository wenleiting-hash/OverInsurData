## 三、发现的 Bug

### 🔴 Bug-1: Auth Token 过期后 UI 状态不恢复

| 项 | 内容 |
|---|---|
| **严重程度** | 高 |
| **页面** | 编辑保险公司表单 |
| **现象** | JWT Token 过期后点击保存，PUT 请求返回 401，但按钮卡在"提交中…"状态，不显示错误提示，无法恢复 |
| **根因** | 401 响应拦截器可能触发了重定向到登录页，但 React 组件未正确清理 isSubmitting 状态 |
| **影响** | 用户长时间未操作后回来保存会卡在提交状态 |

### 🟡 Bug-2: 编辑表单 Step3 "账单格式" 未回显

| 项 | 内容 |
|---|---|
| **严重程度** | 中 |
| **页面** | 编辑保险公司 - Step 3 结算配置 |
| **现象** | 详情页显示账单格式为"API 自动拉取"，但编辑表单 Step3 中该字段显示"请选择"（未回显） |
| **根因** | 后端返回的 `billing_format` 字段值可能与前端 `<select>` 选项的 value 不匹配，或 `billingFormat` 状态未在 useEffect 中设置 |

### 🟡 Bug-3: 详情页首次加载闪 "Loading..."

| 项 | 内容 |
|---|---|
| **严重程度** | 低 |
| **页面** | 保险公司详情页 |
| **现象** | 首次进入详情页时，公司名称短暂显示 "Loading..." 后刷新为正确名称 |
| **根因** | 数据加载期间使用了 fallback 文本而非 Skeleton 骨架屏 |

### 🟡 Bug-4: i18n 翻译缺失 `bulkActions.batchDelete`（已修复）

| 项 | 内容 |
|---|---|
| **严重程度** | 低 |
| **页面** | 保险公司列表 - 批量操作栏 |
| **现象** | 批量删除按钮显示原始 i18n key `bulkActions.batchDelete` 而非"批量删除" |
| **修复** | 已在 zh-CN/insurer.json 和 en-US/insurer.json 的 `bulkActions` 区段添加 `batchDelete` 翻译键 |
