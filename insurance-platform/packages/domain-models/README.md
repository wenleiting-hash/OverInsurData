# Domain Models Package

This package contains the Drizzle ORM schema definitions for the OverInsurData project.

## Directory Structure

```
packages/domain-models/
├── src/
│   └── schema/          # Drizzle Schema definitions
├── drizzle-out/         # Generated SQL migration files
├── scripts/             # Database setup and seed scripts
├── package.json
└── tsconfig.json
```
