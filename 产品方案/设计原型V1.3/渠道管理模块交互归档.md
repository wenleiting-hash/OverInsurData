## 通用布局结构

每个渠道管理子页面遵循统一布局：

```
┌─────────────────────────────────────────────┐
│ 顶部 Banner（InsureOS · 面包屑 · 搜索 · 用户）  │
├──────────┬──────────────────────────────────┤
│          │ H1 标题 + 副标题                  │
│ 侧边栏    │ 时间区间/操作按钮（导出/新增）      │
│ 224px    │ ──────────────────────────────  │
│          │ Tab 区（圆角 10px 10px 0 0）       │
│ 渠道管理  │ ──────────────────────────────  │
│ ├渠道列表 │ 统计卡区（2-4 KPI 卡）             │
│ ├渠道主数据│ ──────────────────────────────  │
│ ├渠道层级 │ 筛选/工具栏（下拉+搜索+操作）       │
│ ├入驻管理 │ ──────────────────────────────  │
│ ├产品授权 │ 数据表格（表头+行，状态彩色 badge） │
│ ├佣金方案 │ ──────────────────────────────  │
│ ├佣金结算 │ [行点击 → 右侧抽屉详情面板]        │
│ ├绩效考核 │                                  │
│ ├培训认证 │                                  │
│ ├渠道门户 │                                  │
│ └渠道分析 │                                  │
└──────────┴──────────────────────────────────┘
```

**主色应用**：品牌蓝 `#0058BC` 用于主按钮、链接、选中态、强调文字、Tab 选中背景（`rgba(0,88,188,0.08~0.09)`）。

**状态 badge**：使用软填充样式（非 outline），如 待审批/已生效/即将到期/已过期/待处理/已解决 等。
