七、渠道主数据管理

### 7.1 渠道组织新增

**功能描述：** 创建新的渠道组织档案（代理机构、经纪公司、MGA、FMO、银保合作方、聚合平台等），录入基本信息、法律实体信息、总部信息、业务信息、资质文件等。

| 操作名称 | 操作说明 |
|---|---|
| 选择组织类型 | 代理机构/经纪公司/MGA/批发经纪/FMO/银保合作方/聚合平台/嵌入式合作伙伴 |
| 填写基本信息 | 组织全称、简称、品牌名、成立年份、官网 |
| 填写法律实体信息 | 法律实体类型（LLC/Corp/Partnership等）、EIN税号 |
| 填写总部信息 | 总部所在城市、州、大区、分区、详细地址 |
| 填写联系信息 | 主要联系人、电话、邮箱 |
| 填写业务信息 | 主营业务线、员工人数、代理人数、年保费规模（预估） |
| 上传资质文件 | 营业执照、机构保险牌照、E&O保险证明、W-9表格 |
| 配置层级关系 | 选择上级组织（FMO/总代），建立层级归属 |
| 配置White-label | 是否启用独立品牌（门户名称、Logo、配色） |
| 保存草稿 | 暂存未完成的录入 |
| 提交审核 | 提交渠道组织档案进入入驻审核流程 |

### 7.2 渠道组织编辑

**功能描述：** 修改已有渠道组织的档案信息，所有变更记录审计日志。

| 操作名称 | 操作说明 |
|---|---|
| 编辑基本信息 | 修改组织名称、简称、官网等基础字段 |
| 编辑法律实体信息 | 修改EIN、实体类型等 |
| 编辑总部/联系信息 | 修改地址、联系人、电话、邮箱 |
| 编辑业务信息 | 修改主营业务线、规模等 |
| 新增/替换附件 | 上传新的资质文件，替换过期文件 |
| 删除附件 | 删除不再需要的附件 |
| 调整层级关系 | 修改上级组织归属（需审批） |
| 修改White-label配置 | 修改品牌名称、Logo、门户配色 |
| 保存修改 | 提交修改，记录变更日志 |
| 查看变更历史 | 查看该组织所有历史修改记录 |
| 字段级变更对比 | 对比某两次修改的字段差异 |

### 7.3 渠道组织停用/启用

**功能描述：** 控制渠道组织的合作状态，停用后不再新增业务，已有保单和佣金继续处理。

| 操作名称 | 操作说明 |
|---|---|
| 停用渠道组织 | 将状态改为"已停用"，停止新业务分配 |
| 启用渠道组织 | 从"已停用"恢复为"合作中" |
| 填写停用原因 | 停用必须选择原因（业务终止/合规问题/主动退出等） |
| 影响范围预览 | 停用前展示受影响的代理人数、在途保单数、未结佣金 |
| 下属代理人处理 | 选择下属代理人的处理方式（随组织停用/转移到其他组织） |
| 批量停用 | 勾选多个渠道组织批量停用 |
| 批量启用 | 勾选多个渠道组织批量启用 |
| 停用审批 | 停用操作需主管审批后生效 |

| 查看合作保险公司 | 展示所有合作保险公司及产品授权范围 |
| 查看可售产品 | 展示该组织获得授权的所有产品列表 |
| 查看可售区域 | 展示该组织授权的可售州/区域 |
| 查看业绩概览 | 展示保费、保单数、件均、赔付率、续保率、佣金 |
| 查看佣金方案 | 展示该组织绑定的所有佣金方案 |
| 查看Appointment状态 | 展示各保险公司各州的Appointment状态 |
| 查看变更历史 | 展示档案信息的变更记录 |
| 跳转编辑 | 进入组织编辑页面 |
| 跳转业绩详情 | 进入组织业绩分析页面 |
| 导出组织报告 | 将组织详情导出为PDF |

|---|---|

### 7.6 代理人新增

**功能描述：** 在指定渠道组织下创建代理人个人档案，录入个人信息、NPN、持牌信息、所属组织、层级关系、佣金方案等。

| 操作名称 | 操作说明 |
|---|---|
| 选择所属组织 | 从渠道组织中选择归属机构 |
| 填写个人信息 | 姓名、性别、生日、SSN后4位 |
| 填写联系信息 | 手机号、邮箱、通讯地址 |
| 填写NPN | 录入National Producer Number |
| 填写持牌信息 | 持牌州、持牌业务线（P&C/Life/Health等） |
| 填写代理人编号 | 保险公司内部代理人编号（如有） |
| 配置层级关系 | 选择直接上级（团队长/推荐人） |
| 配置佣金方案 | 选择个人级佣金方案（覆盖组织默认） |
| 上传资质文件 | 上传牌照复印件、E&O保险、身份证明等 |
| 设置入职日期 | 代理人签约/入职日期 |
| 保存草稿 | 暂存未完成的录入 |
| 提交审核 | 提交代理人档案进入审核流程 |
| NIPR预校验 | 提交前调用NIPR校验NPN和持牌信息 |

### 7.8 代理人状态管理

**功能描述：** 管理代理人的从业状态，控制其系统操作权限。

| 操作名称 | 操作说明 |
|---|---|
| 激活代理人 | 将状态从"待入驻"改为"有效"，开通全部权限 |
| 暂停代理人 | 临时暂停（牌照过期/合规调查/休假），暂停出单权限 |
| 恢复代理人 | 从"暂停"恢复为"有效" |
| 终止代理人 | 终止合作（离职/违规/主动退出），永久关闭权限 |
| 标记休假/停薪留职 | 标记为暂时不活跃，保留档案但不分配新业务 |
| 标记非活跃 | 长期无出单的代理人自动标记为非活跃 |
| 填写状态变更原因 | 每次状态变更必须选择原因并填写备注 |
| 影响范围预览 | 暂停/终止前展示在途保单、未结佣金 |
| 批量状态变更 | 勾选多个代理人批量修改状态 |
| 状态变更审批 | 暂停/终止需主管审批后生效 |
| 状态变更历史 | 查看代理人所有状态变更记录 |

### 7.12 资质文件管理

**功能描述：** 集中管理渠道组织和代理人的各类资质文件，支持文件类型分类、有效期设置、到期提醒、审核确认。

| 操作名称 | 操作说明 |
|---|---|
| 上传资质文件 | 为组织/代理人上传资质文件（选择文件类型） |
| 文件类型分类 | 营业执照/机构牌照/个人牌照/E&O保险/W-9/身份证明/其他 |
| 设置有效期 | 为有有效期的文件设置到期日期 |
| 文件预览 | 在线预览PDF/图片格式的文件 |
| 文件下载 | 下载资质文件原件 |
| 文件替换 | 上传新版本替换过期文件 |
| 文件删除 | 删除不再需要的文件 |
| 到期提醒 | 文件到期前自动提醒更新 |
| 即将到期列表 | 展示30/60/90天内到期的资质文件 |
| 已过期列表 | 展示已过期未更新的资质文件 |
| 批量上传 | 一次性上传多个资质文件 |
| 文件审核 | 上传的资质文件需运营审核确认有效性 |
| 导出文件清单 | 将资质文件清单导出 |
