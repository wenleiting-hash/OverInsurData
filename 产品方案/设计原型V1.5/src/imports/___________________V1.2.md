# 第一部分：保险公司管理模块

## 一、保险公司主数据管理

### 1.1 保险公司新增

**功能描述：** 创建新的保险公司档案，录入基本信息、监管信息、财务评级等，建立平台与保险公司的合作基础。

| 操作名称 | 操作说明 |
|---|---|
| 填写基本信息 | 录入公司全称、简称、中文译名、成立年份、官网 |
| 填写监管信息 | 录入NAIC编码、公司类型（Admitted/Non-Admitted） |
| 填写总部信息 | 选择总部所在城市、州、大区、分区 |
| 填写财务评级 | 录入AM Best、S&P、Moody's、Fitch评级及评级日期 |
| 填写结算信息 | 配置佣金结算周期（月/季）、账单格式（CSV/Excel/EDI/API） |
| 上传资质文件 | 上传营业执照、监管批文、评级报告等附件 |
| 保存草稿 | 暂存未完成的录入信息，可后续继续编辑 |
| 提交审核 | 提交保险公司档案进入审核流程 |
| 重置表单 | 清空当前已填写内容 |

### 1.2 保险公司编辑

**功能描述：** 修改已有保险公司的档案信息，支持部分字段更新，所有变更记录审计日志。

| 操作名称 | 操作说明 |
|---|---|
| 编辑基本信息 | 修改公司名称、简称、官网等基础字段 |
| 编辑监管信息 | 修改NAIC编码、公司类型等监管字段 |
| 编辑财务评级 | 更新评级机构评级及评级日期 |
| 编辑结算信息 | 修改结算周期、账单格式等财务配置 |
| 新增/替换附件 | 上传新的资质文件，替换过期文件 |
| 删除附件 | 删除不再需要的附件文件 |
| 保存修改 | 提交修改，系统自动记录变更前后值 |
| 查看变更历史 | 查看该保险公司所有历史修改记录 |
| 字段级变更对比 | 对比某两次修改之间的字段差异 |

### 1.3 保险公司停用/启用

**功能描述：** 控制保险公司的合作状态，停用后不再分配新业务但已有保单和佣金继续正常处理。

| 操作名称 | 操作说明 |
|---|---|
| 停用保险公司 | 将状态改为"已停用"，停止新业务分配 |
| 启用保险公司 | 将状态从"已停用"恢复为"合作中" |
| 填写停用原因 | 停用必须选择原因（业务终止/合规问题/系统迁移等） |
| 影响范围预览 | 停用前展示受影响的渠道数、产品数、在途保单数 |
| 批量停用 | 勾选多家保险公司批量停用 |
| 批量启用 | 勾选多家保险公司批量启用 |
| 停用审批 | 停用操作需主管审批后生效 |

### 1.4 保险公司详情查看

**功能描述：** 查看保险公司的完整档案信息及关联业务数据的一站式页面。

| 操作名称 | 操作说明 |
|---|---|
| 查看基本信息 | 展示公司全称、简称、NAIC、总部、成立时间等 |
| 查看财务评级 | 展示各评级机构当前及历史评级 |
| 查看关联产品列表 | 展示该保险公司下所有产品及状态 |
| 查看合作渠道列表 | 展示所有合作渠道及合作状态、业绩 |
| 查看业绩概览 | 展示保费、保单数、赔付率、增长率等核心指标 |
| 查看佣金方案 | 展示该保险公司关联的所有佣金方案 |
| 查看资质附件 | 预览和下载所有上传的附件文件 |
| 查看变更历史 | 展示档案信息的所有变更记录 |
| 跳转产品管理 | 点击产品跳转到产品详情页 |
| 跳转渠道详情 | 点击渠道跳转到渠道详情页 |
| 导出详情报告 | 将保险公司详情导出为PDF |

### 1.5 保险公司列表查询

**功能描述：** 以列表形式展示所有保险公司，支持多条件筛选、排序、分页。

| 操作名称 | 操作说明 |
|---|---|
| 关键词搜索 | 按公司名称、简称、NAIC编码模糊搜索 |
| 按公司类型筛选 | 筛选Admitted/Non-Admitted |
| 按状态筛选 | 筛选合作中/已停用/待审核 |
| 按评级筛选 | 按AM Best评级区间筛选 |
| 按大区筛选 | 按总部所在大区筛选 |
| 按业务线筛选 | 按主营业务线筛选 |
| 排序 | 按保费规模、成立时间、名称等升序/降序 |
| 分页浏览 | 翻页、调整每页显示条数（10/20/50/100） |
| 自定义列 | 选择列表展示哪些字段列 |
| 保存筛选方案 | 将当前筛选条件保存为常用方案，一键调用 |
| 重置筛选 | 清空所有筛选条件 |

### 1.6 批量导入

**功能描述：** 通过Excel模板批量导入保险公司数据，支持校验和错误反馈。

| 操作名称 | 操作说明 |
|---|---|
| 下载导入模板 | 下载标准Excel导入模板（含字段说明和示例） |
| 上传文件 | 选择本地Excel文件上传 |
| 数据预览 | 上传后预览解析出的数据，确认无误后提交 |
| 字段映射 | 若模板列名不匹配，手动映射Excel列与系统字段 |
| 数据校验 | 系统自动校验必填项、格式、重复值、NAIC编码合法性 |
| 错误报告下载 | 校验不通过时下载错误报告，标明行号和错误原因 |
| 确认导入 | 校验通过后确认执行导入 |
| 导入结果反馈 | 展示成功条数、失败条数、跳过条数 |
| 查看导入历史 | 查看历史批量导入记录及结果 |

### 1.7 批量导出

**功能描述：** 将保险公司列表及关联数据导出为Excel/CSV文件。

| 操作名称 | 操作说明 |
|---|---|
| 选择导出范围 | 导出当前筛选结果 / 勾选的记录 / 全部数据 |
| 选择导出字段 | 勾选需要导出的字段列 |
| 选择导出格式 | Excel(.xlsx) / CSV |
| 选择是否含关联数据 | 是否同时导出关联产品、渠道、业绩数据 |
| 执行导出 | 生成文件并下载 |
| 导出任务记录 | 查看历史导出任务及下载文件 |

### 1.8 变更历史

**功能描述：** 记录保险公司档案所有字段的变更，支持审计追溯。

| 操作名称 | 操作说明 |
|---|---|
| 按时间筛选 | 按变更日期范围筛选 |
| 按操作人筛选 | 按执行变更的用户筛选 |
| 按字段筛选 | 按变更的具体字段筛选 |
| 查看变更详情 | 查看某条变更的字段前后值对比 |
| 查看完整变更链 | 查看某个字段从创建至今的所有变更 |
| 导出变更日志 | 将变更记录导出为Excel |

### 1.9 重复数据检测

**功能描述：** 自动检测保险公司数据中的重复记录，提示合并处理。

| 操作名称 | 操作说明 |
|---|---|
| 启动检测 | 按NAIC编码、公司名称（模糊匹配）检测重复 |
| 查看重复组 | 展示检测到的重复记录组 |
| 对比重复记录 | 并排展示两条记录的字段差异 |
| 选择主记录 | 选择保留哪条作为主记录 |
| 合并记录 | 将重复记录合并，关联数据迁移到主记录 |
| 标记非重复 | 确认不是重复记录，标记并排除 |
| 忽略检测结果 | 忽略该重复提示 |

## 二、保险产品管理

### 2.1 产品新增

**功能描述：** 在指定保险公司下创建新的保险产品，配置产品基本属性、业务线、条款、核保规则等。

| 操作名称 | 操作说明 |
|---|---|
| 选择所属保险公司 | 从已入驻保险公司中选择 |
| 填写产品基本信息 | 产品全称、简称、产品代码、条款编号 |
| 选择业务线 | 选择主业务线（AUTO/HOME/LIFE/HEALTH等） |
| 选择子险种 | 选择更细粒度的子险种分类 |
| 选择产品类型 | 个人险/团体险/自愿福利险 |
| 配置核保模式 | 自动核保/人工核保/MGA委托核保 |
| 配置出单授权 | 保险公司出单/MGA出单/代理人出单 |
| 设置出单限额 | 配置代理人最大可出单保费限额 |
| 配置续保类型 | 保证续保/有条件续保/定期不续保 |
| 设置保险期间 | 最长保险期间（年）、可选期间 |
| 配置可售州 | 勾选产品获批销售的州 |
| 设置生效/停售日期 | 产品上市日期和计划停售日期 |
| 上传产品文件 | 上传条款、费率手册、销售指南等附件 |
| 保存草稿 | 暂存未完成的产品配置 |
| 提交审核 | 提交产品进入上架审核流程 |

### 2.2 产品编辑

**功能描述：** 修改已有产品的配置信息，重要字段变更需版本管理。

| 操作名称 | 操作说明 |
|---|---|
| 编辑基本信息 | 修改产品名称、简称、代码等 |
| 编辑业务属性 | 修改业务线、子险种、产品类型 |
| 编辑核保规则 | 修改核保模式、出单授权、出单限额 |
| 编辑可售州 | 增加或移除可销售的州 |
| 编辑续保配置 | 修改续保类型和保险期间 |
| 上传/替换附件 | 更新产品条款、费率手册等文件 |
| 删除附件 | 删除不再需要的产品文件 |
| 保存修改 | 提交修改，生成新版本 |
| 查看版本历史 | 查看产品所有历史版本 |
| 版本对比 | 对比任意两个版本的字段差异 |
| 回滚版本 | 将产品回滚到指定历史版本 |

### 2.3 产品上下架

**功能描述：** 控制产品的销售状态，上架后可被渠道报价出单，下架后停止新单。

| 操作名称 | 操作说明 |
|---|---|
| 上架产品 | 将产品状态改为"在售"，渠道可开始销售 |
| 下架产品 | 将产品状态改为"停售"，不再接受新单报价 |
| 暂停销售 | 临时暂停销售（如费率调整中），可恢复 |
| 恢复销售 | 从暂停状态恢复为在售 |
| 填写下架原因 | 下架必须选择原因（产品停售/费率调整/合规问题等） |
| 影响范围预览 | 下架前展示受影响的渠道数、在途报价单数 |
| 批量上架 | 勾选多个产品批量上架 |
| 批量下架 | 勾选多个产品批量下架 |
| 定时上下架 | 设置产品在指定日期自动上架/下架 |
| 下架审批 | 产品下架需主管审批后生效 |

### 2.8 产品核保规则配置

| 操作名称 | 操作说明 |

## 三、我司与保险公司合作管理

> **模块定位说明：** 本模块管理**我司（平台方）与上游保险公司**的合作关系，以及**我司将保险公司产品资源授权给下游渠道**的中间授权链路。
>
> **三方关系区分：**
> - **上游合作（本模块 3.1–3.6）：** 我司 ↔ 保险公司 —— 签约、合同、结算参数、对接人、续约
> - **中间授权（本模块 3.7–3.9）：** 保险公司产品资源 → 我司 → 渠道 —— 产品接入、对渠道授权、出单权限与限额
> - **下游管理（渠道管理模块）：** 我司 ↔ 渠道合作商 —— 入驻、层级、佣金、绩效、培训、门户
>
> 我司作为中间平台，从保险公司获取产品资源和出单权限，再授权给我司发展的渠道合作商使用。

### 3.1 我司与保险公司合作关系建立

**功能描述：** 创建我司（平台方）与保险公司之间的合作关系，配置合作类型、基础参数和结算方式。这是平台获取保险公司产品资源的前提。
