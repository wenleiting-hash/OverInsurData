## 1. 前置条件检查

### 1.1 必需软件版本要求

| 软件 | 最低版本 | 推荐版本 | 检查命令 |
|------|---------|---------|----------|
| Node.js | 18.x | 20.x LTS | `node -v` |
| npm/pnpm | 9.x | 9.15+ | `pnpm -v` |
| Git | 2.x | 2.40+ | `git -v` |
| Docker (可选) | 24.x | 27.x | `docker --version` |

### 1.2 系统资源要求

```bash
内存：至少 8GB 可用（建议 16GB）
磁盘空间：至少 5GB 可用
端口占用：
  - 前端：3001
  - Carrier Service: 8080
```

### 1.3 执行环境检测脚本

**文件位置**: `scripts/check-environment.bat` (Windows)

```batch
@echo off
chcp 65001 >nul
echo ================================
echo    环境检测工具 v1.0
echo ================================
echo.

:: 检查 Node.js
where node >nul 2>nul
if %errorlevel%==0 (
    echo [OK] Node.js 已安装
    for /f "tokens=*" %%i in ('node -v') do echo      版本：%%i
) else (
    echo [ERROR] Node.js 未安装！
    echo       请访问：https://nodejs.org/
)
echo.

:: 检查 pnpm
where pnpm >nul 2>nul
if %errorlevel%==0 (
    echo [OK] pnpm 已安装
    for /f "tokens=*" %%i in ('pnpm -v') do echo      版本：%%i
) else (
    echo [WARN] pnpm 未安装，正在尝试通过 npm 安装...
    call npm install -g pnpm >nul 2>&1
    if %errorlevel%==0 (
        echo [OK] pnpm 安装成功
    ) else (
        echo [ERROR] pnpm 安装失败！
    )
)
echo.

:: 检查端口占用
netstat -ano | findstr :3001 >nul
if %errorlevel%==0 (
    echo [WARN] 端口 3001 被占用，请关闭其他应用
) else (
    echo [OK] 端口 3001 可用
)

netstat -ano | findstr :8080 >nul
if %errorlevel%==0 (
    echo [WARN] 端口 8080 被占用，请关闭其他应用
) else (
    echo [OK] 端口 8080 可用
)

echo.
echo ================================
echo   检测完成
echo ================================
pause
```

## 3. 快速启动命令

### 3.1 Windows PowerShell 一键启动脚本

**文件位置**: `scripts/start-test-env.ps1`

```powershell
#!/usr/bin/env pwsh
# Test Environment Starter for InsureOS Platform
# Version: 1.0
# Date: 2026-09-04

$ErrorActionPreference = "Stop"

# Colors for output
$GREEN = [ConsoleColor]::Green
$RED = [ConsoleColor]::Red
$YELLOW = [ConsoleColor]::Yellow
$BLUE = [ConsoleColor]::Blue

Write-Host "=====================================" -ForegroundColor $BLUE
Write-Host "  InsureOS 测试环境启动脚本 v1.0" -ForegroundColor $BLUE
Write-Host "=====================================" -ForegroundColor $BLUE
Write-Host ""

# Check Node version
Write-Host "[Step 1/6] Checking Node.js version..." -ForegroundColor Yellow
$nodeVersion = & node -v 2>&1
if ($LASTEXITCODE -ne 0) {
    Write-Host "❌ Node.js is not installed!" -ForegroundColor Red
    exit 1
}
Write-Host "✓ Node.js version: $nodeVersion" -ForegroundColor $GREEN

# Install dependencies
Write-Host ""
Write-Host "[Step 2/6] Installing dependencies..." -ForegroundColor Yellow
cd "$PSScriptRoot/../insurance-platform"

if (-not (Test-Path "node_modules")) {
    Write-Host "Installing with pnpm..." -ForegroundColor $YELLOW
    pnpm install
    if ($LASTEXITCODE -ne 0) {
        Write-Host "Failed to install dependencies!" -ForegroundColor Red
        exit 1
    }
} else {
    Write-Host "✓ Dependencies already installed" -ForegroundColor $GREEN
}

# Build carrier service
Write-Host "" 
Write-Host "[Step 3/6] Building Carrier Service..." -ForegroundColor Yellow
cd "../insurance-platform/apps/carrier-service"
if (-not (Test-Path "dist")) {
    Write-Host "Building TypeScript..." -ForegroundColor $YELLOW
    pnpm run build
    if ($LASTEXITLINE -ne 0) {
        Write-Host "Failed to build carrier service!" -ForegroundColor Red
        exit 1
    }
    Write-Host "✓ Carrier Service built successfully" -ForegroundColor $GREEN
} else {
    Write-Host "✓ Dist folder exists, skipping build" -ForegroundColor $GREEN
}

# Start services in parallel
Write-Host "" 
Write-Host "[Step 4/6] Starting services..." -ForegroundColor Yellow

$carrierServiceStart = Start-Process powershell -ArgumentList "-NoExit","-Command","cd '$PSScriptRoot/../insurance-platform/apps/carrier-service'; pnpm run dev" -PassThru
Write-Host "✓ Carrier Service starting on http://localhost:8080" -ForegroundColor $GREEN

# Wait a bit for backend
Write-Host "Waiting for Carrier Service to start..." -ForegroundColor $YELLOW
Start-Sleep -Seconds 8

$frontEndStart = Start-Process powershell -ArgumentList "-NoExit","-Command","cd '$PSScriptRoot/../insurance-platform/apps/web-carrier-admin'; pnpm run dev" -PassThru
Write-Host "✓ Frontend starting on http://localhost:3001" -ForegroundColor $GREEN

Write-Host ""
Write-Host "=====================================" -ForegroundColor $GREEN
Write-Host "  ✅ 测试环境启动成功！" -ForegroundColor $Green
Write-Host "=====================================" -ForegroundColor $GREEN
Write-Host ""
Write-Host "访问地址:" -ForegroundColor Cyan
Write-Host "  🌐 Frontend: http://localhost:3001" -ForegroundColor White
Write-Host "  🔧 Backend:  http://localhost:8080" -ForegroundColor White
Write-Host ""
Write-Host "默认账户：" -ForegroundColor Cyan
Write-Host "  👤 Username: admin" -ForegroundColor White
Write-Host "  🔑 Password: admin123" -ForegroundColor White
Write-Host ""
Write-Host "按任意键查看日志窗口..." -ForegroundColor Yellow
[Console]::ReadKey($true) | Out-Null
```

```powershell

# 如果有错误，记录具体 error message 再联系支持
```

#### **步骤 1.3：确认数据库配置（可选）**

当前配置使用本地 SQLite 或 memory database 进行演示。如需连接真实 PostgreSQL：

**配置文件**: `services/carrier-service/src/database/drizzle.client.ts`

```typescript
import { drizzle } from 'drizzle-orm/node-postgres';
import { Pool } from 'pg';

const pool = new Pool({
  host: process.env.DB_HOST || 'localhost',
  port: parseInt(process.env.DB_PORT || '5432'),
  user: process.env.DB_USER || 'postgres',
  password: process.env.DB_PASSWORD || 'password',
  database: process.env.DB_NAME || 'db_master_data',
});

export const db = drizzle(pool);
```

如需启用，先设置环境变量：

```powershell
# PowerShell (.env.ps1)
$env:DB_HOST = "localhost"
$env:DB_PORT = "5432"
$env:DB_USER = "postgres"
$env:DB_PASSWORD = "your_password"
$env:DB_NAME = "db_carrier"
```

## 6. 常见问题排查

### 6.1 端口冲突

**问题**: `Port 3001 is already in use`

**解决方案**:
```powershell
# 查找占用端口的进程 ID
Get-NetTCPConnection -LocalPort 3001 | Select-Object Owner

# 终止进程（替换 <PID> 为实际进程 ID）
taskkill /F /PID <PID>
```

### 6.2 依赖安装失败

**问题**: `pnpm install` 报 Network timeout

**解决方案**:
```powershell
# 切换镜像源
pnpm config set registry https://registry.npmmirror.com

# 清理缓存后重新安装
pnpm store cleanup
rm -r node_modules
pnpm install
```

### 6.3 前端无法访问后端

**问题**: CORS 错误或网络请求失败

**检查项**:
1. 确认后端服务已启动 (`http://localhost:8080`)
2. 检查 `web-carrier-admin/vite.config.ts` 代理配置
3. 查看浏览器 Console 的错误详情

### 6.4 后端类型编译错误

**问题**: `TypeScript compilation failed`

**解决方案**:
```powershell
cd insurance-platform\apps\carrier-service

# 清理编译产物
cd services\carrier-service
Remove-Item -Recurse -Force dist

# 重新编译
pnpm run build
```

## 8. 附录：故障恢复方案

### 8.1 完全重装依赖

**当依赖混乱导致无法启动时**

```powershell
cd insurance-platform

# 1. 删除所有 node_modules 和锁文件
Remove-Item -Recurse -Force node_modules
Remove-Item -Force pnpm-lock.yaml

# 2. 清理 pnpm 存储
pnpm store cleanup

# 3. 全新安装
pnpm install

# 4. 分别启动各服务
# ❌ 旧路径已废弃：cd services/carrier-service
# ✅ 新路径（NestJS Workspace）:
cd insurance-platform\apps\carrier-service
pnpm run build
cd ../insurance-platform/apps/web-carrier-admin
```

### 8.2 重置本地数据库（如果使用 SQLite）

**当数据损坏需要重置时**

```powershell
# 找到数据库文件（通常在 insurance-platform/apps/carrier-service/data/）
cd insurance-platform\apps\carrier-service
Remove-Item -Force data/*.sqlite

# 重启服务，Drizzle 会自动重建 schema
```

### 8.3 回滚到已知可用的 Git Commit

**当最近修改导致问题时**

```powershell
# 查看提交历史
git log --oneline -10

# 回退到指定 commit
git reset --hard <commit-hash>

# 强制推送到远程（谨慎操作）
git push --force
```
