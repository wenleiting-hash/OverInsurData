## 🎯 启动流程推荐

### 新手初次搭建
```
步骤 1: 阅读 [测试环境启动手册 V1.0.md] (第 1 节 - 前置条件检查)
步骤 2: 执行环境检测脚本 (scripts/check-environment.bat)
步骤 3: 运行一键启动脚本 (启动测试环境.bat 或 scripts/start-test-env.ps1)
步骤 4: 使用 [快速启动指南] 进行日常操作
```

### 日常开发启动
```
最快捷方式: 双击 Windows 桌面上的「启动测试环境.bat」
替代方式：打开两个终端窗口，分别执行快速指南中的命令
```

### 遇到问题时
```
1. 查看 [快速启动指南] 的"常见问题速查"章节
2. 若问题复杂，参考 [测试环境启动手册] 的详细排查方案
3. 仍无法解决，收集日志后联系技术支持
```

## 🛠️ 配套工具脚本

| 脚本名称 | 位置 | 功能 |
|---------|------|------|
| `启动测试环境.bat` | 项目根目录 | Windows 双激启动入口 |
| `scripts/start-test-env.ps1` | scripts/ | PowerShell 自动启动脚本 |
| `scripts/verify-environment.ps1` | scripts/ | 环境健康状态检查工具 |

**使用方法**:
```powershell
# 方式 1: 直接双击 .bat 文件（最简捷）
cd e:\WorkProject\OverInsurData
双击「启动测试环境.bat」

# 方式 2: PowerShell 命令行
.\scripts\start-test-env.ps1

# 方式 3: 先检查再启动
.\scripts\verify-environment.ps1
(检查通过后询问是否立即启动)
```

## 🔐 安全注意事项

⚠️ **重要提醒**:
1. 本配置文件仅适用于**本地开发 / 测试环境**
2. 默认密码需要在生产环境中修改
3. JWT Secret 应通过环境变量设置，禁止硬编码
4. 开启 HTTPS 前需配置证书
5. 数据库连接字符串需妥善保护

详见 [测试环境启动手册 V1.0.md](./测试环境启动手册 V1.0.md#7-环境变量配置)
