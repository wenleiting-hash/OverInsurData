## 1. 部署背景

本迭代将「业务线 → 子险种 / 承保范围」联动字典入库（四表：`insurance_line` / `insurance_sub_line` / `insurance_coverage` / `line_coverage_rel`），新增系统管理→险种字典管理界面与 `/api/dictionaries/*` 接口族，并完成三个消费方动态化：

1. **后端（carrier-api）**：新增 `dictionary` 模块（CRUD + coverage-tree + usage + 进程内缓存 + 审计）；`integration` 模块 match 校验改读字典缓存（新增错误码 `INVALID_COVERAGES_FOR_LOB`）+ 新增 I4 `GET /api/integration/v1/insurance-catalog` 快照接口。
2. **前端（web-carrier-admin）**：新增险种字典管理页（3 Tab：业务线/承保范围/联动矩阵）；ProductForm 承保范围/子险种改为字典联动（历史 PascalCase 值归一化回显、未知值置灰）；侧边栏新菜单。
3. **模拟器（workos-simulator.html）**：加载时拉取 I4 快照渲染业务线/子险种/承保范围，3s 超时降级内置只读快照。

### 1.1 本次修复内容（V1.0.3 增量）

1. **ProductForm 承保范围联动修复**：
   - 修复新增产品时 `coverages` 预填 `['liability','comprehensive','collision']` 导致矩阵无关联仍显示3项的问题 → 改为空数组 `[]`。
   - 修复 `availableCoverages` 在业务线矩阵无关联时兜底全量 9 项的问题 → 改为空（显示"该业务线暂未配置承保范围"提示）。
   - 修复 `toCoverageKey` 带空格值归一化不命中 → 查表前先 `trim()`。
   - 新增 i18n key `form.basic.coverageEmpty`（双语）。
2. **模拟器联动修复**：
   - 修复 `renderCovGrid()` 矩阵无关联时兜底全量 `allCoverages` → 改为空（显示提示）。
   - 修复 appKey/appSecret 未预填导致 `loadCatalog()` 失败降级 → 预填本地开发凭证，页面加载即从 I4 获取数据库最新业务线。
