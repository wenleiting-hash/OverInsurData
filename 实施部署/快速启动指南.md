## 🔌 API 接口测试

### Swagger UI

后端内置 Swagger 文档，启动后访问：**http://localhost:8080/api**

> 支持在线查看所有接口定义、参数 Schema，并直接在页面内发送请求调试。

### 认证流程

所有业务接口需要 Bearer Token，先登录获取：

```powershell
# 1. 登录获取 Token
$login = Invoke-RestMethod -Uri http://localhost:8080/api/auth/login `
  -Method Post -ContentType 'application/json' `
  -Body '{"username":"admin","password":"admin123"}'

# 2. 提取 Token（注意 token 在 data.accessToken 层级下）
$token = $login.data.accessToken

# 3. 后续请求携带 Token
$h = @{ Authorization = "Bearer $token" }
```

> **注意**：Token 有效期约 1 小时，过期后接口返回 401，需重新登录或用 refresh token 刷新。


### 常见接口测试注意事项

1. **Content-Type**：JSON 接口用 `application/json`；文件上传用 `multipart/form-data`（不要手动设 Content-Type，让 curl/浏览器自动加 boundary）
2. **ValidationPipe 严格模式**：后端拒绝未知字段（`forbidNonWhitelisted: true`），请求体只能包含 DTO 中定义的字段
3. **JWT 过期**：Token 约 1 小时过期，过期后返回 401，需重新登录
4. **CORS**：后端仅允许 `localhost:3001` 和 `localhost:5173` 的跨域请求；curl/server-to-server 不受限

### 外部系统集成与模拟调用

平台提供 **workOS 集成联调模拟器**（纯前端页面，内置 HMAC-SHA256 签名计算），可模拟外部系统调用 S2S 接口，无需手动计算签名。

**模拟器地址**：http://localhost:3001/workos-simulator.html

**使用流程**：
1. 先在「接入应用管理」页面（`/integration-apps`）新建应用，获取 appKey + appSecret
2. 打开模拟器页面，在「全局配置」中填入 appKey 和 appSecret
3. 选择对应 Tab 发送请求（签名自动计算）：
   - **SSO 单点登录** — 模拟 workOS 员工选择 → 生成 code+state → 跳转子系统回调
   - **I1 权限目录** — GET `/api/integration/v1/permission-catalog`
   - **I2 用户同步** — POST `/api/integration/v1/users/upsert`（表单构建请求体）
   - **I3 保单咨询** — POST `/api/integration/v1/consultation/match`（表单构建请求体）
   - **通用请求** — 任意 method + path + body 的签名调用（调试用）

**S2S 接口列表**：

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 权限目录 | GET | `/api/integration/v1/permission-catalog` | 获取系统权限目录 |
| 用户同步 | POST | `/api/integration/v1/users/upsert` | 用户/角色 upsert |
| 保单咨询匹配 | POST | `/api/integration/v1/consultation/match` | 保单咨询匹配 |

**鉴权方式**（HMAC-SHA256 签名，非 Bearer Token）：

每次请求需携带 4 个请求头：`x-app-key`、`x-timestamp`（±300秒）、`x-nonce`（防重放）、`x-signature`。

```
签名串 = METHOD + "\n" + 路径 + "\n" + timestamp + "\n" + nonce + "\n" + SHA256(请求体JSON)
签名 = HMAC-SHA256(appSecret, 签名串)
```

> 模拟器页面会自动完成签名计算和 JSON 标准化，直接点击按钮即可发送。手动调用示例见测试环境启动手册 9.8 节。

## ⚠️ 常见问题速查

### 问题 1：端口被占用
```powershell
# 查找占用进程
Get-NetTCPConnection -LocalPort 3001 | Select-Object OwnerProcessId

# 终止进程 (替换<PID>)
taskkill /F /PID <PID>
```

### 问题 2：依赖安装失败
```powershell
cd insurance-platform
pnpm store cleanup
rm -r node_modules
pnpm install --registry https://registry.npmmirror.com
```

### 问题 3：后端编译错误
```powershell
cd insurance-platform\services\carrier-service
Remove-Item -Recurse -Force dist
pnpm run build
```

### 问题 4：前端无法访问后端
1. 确认后端正在运行 (`curl http://localhost:8080/api/carrier`)
2. 检查 CORS 配置
3. 查看浏览器 Console 网络请求详情
