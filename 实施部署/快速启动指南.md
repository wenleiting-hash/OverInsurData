## 🔧 手动启动（高级用户）

### **Terminal 1 - 启动后端服务** ⭐
```powershell
cd insurance-platform\apps\carrier-service
pnpm run dev
```

**说明**: 后端服务现在位于 `insurance-platform/apps/`下，不再在根目录的`services/` 子目录。

### **Terminal 2 - 启动前端应用**
```powershell
cd insurance-platform\apps\web-carrier-admin
pnpm run dev
```

等待出现以下提示即为成功：
- Backend: `Carrier Service running on http://localhost:8080`
- Frontend: `Local:   http://localhost:3001/`

## ⚠️ 常见问题速查

### 问题 1：端口被占用
```powershell
# 查找占用进程
Get-NetTCPConnection -LocalPort 3001 | Select-Object OwnerProcessId

# 终止进程 (替换<PID>)
taskkill /F /PID <PID>
```

### 问题 2：依赖安装失败
```powershell
cd insurance-platform
pnpm store cleanup
rm -r node_modules
pnpm install --registry https://registry.npmmirror.com
```

### 问题 3：后端编译错误
```powershell
cd insurance-platform\services\carrier-service
Remove-Item -Recurse -Force dist
pnpm run build
```

### 问题 4：前端无法访问后端
1. 确认后端正在运行 (`curl http://localhost:8080/api/carrier`)
2. 检查 CORS 配置
3. 查看浏览器 Console 网络请求详情

## 🛠️ 进阶操作

### 完全重装依赖
```powershell
# 删除所有 node_modules
Remove-Item -Recurse -Force insurance-platform/node_modules
pnpm store cleanup
pnpm install

# 重新构建
cd insurance-platform\services\carrier-service
pnpm run build
```

### 修改服务端口
编辑配置文件后重启：

**后端**: `services/carrier-service/src/main.ts`
```typescript
const port = process.env.PORT || 8081; // 改为新端口
```

**前端**: `apps/web-carrier-admin/vite.config.ts`
```typescript
server: { port: 3002, } // 改为新端口
proxy: { '/api': { target: 'http://localhost:8081' } } // 同步修改
```
