# 实施部署 V1.0.2 — 集成接口更新 + 数据回显修复

**文档版本：** V1.0.2  **部署日期：** 2026-09-24  **文档类型：** 部署计划与执行记录（补归档）
**关联内容：** 产品详情回显修复、保司资质附件修复、集成接口（integration 模块）更新、集成联调模拟器

---

## 1. 部署背景

1. **前端（web-carrier-admin）**：产品详情页「产品文件」展示、费率方案/核保规则 tab 回显建品配置；保险公司详情页资质附件接入真实 documents；i18n 中英文补齐。经 tsc、生产构建、中英双语截图验证通过。
2. **后端（carrier-api）**：集成接口更新——本地与生产源码比对后，3 个文件存在差异需同步：
   - `src/modules/integration/integration.service.ts`
   - `src/modules/integration/v1.controller.ts`
   - `src/modules/integration/dtos/integration.dto.ts`
3. **集成联调模拟器**：`public/workos-simulator.html` 随前端 dist 一并发布（vite public 目录自动拷入 dist）。

**数据库：无迁移。** `integration_app` / `integration_nonce` 表此前已建立（迁移 v1016 已应用），且存在 active 应用凭证（workOs）。

## 2. 前置条件

- 本地 `pnpm --filter web-carrier-admin build` 通过（仅既存 INEFFECTIVE_DYNAMIC_IMPORT 警告）。
- SSH 免密连通：`ssh -p 50222 root@220.154.128.28`。
- 生产 nginx 8601 → carrier-api 8610（容器端口映射 `127.0.0.1:8610->8080/tcp`）。

## 3. 部署步骤（实际执行记录）

### 3.1 前端

```bash
# 1) 构建
pnpm --filter web-carrier-admin build
# 2) 打包（dist 内容打 tar）
tar -czf dist-web-carrier.tar.gz -C dist .
# 3) 线上备份
ssh -p 50222 root@220.154.128.28 \
  "cd /opt/overinsur/deploy && tar -czf web-backup-20260928.tar.gz web/"
# 4) 上传并原子替换 assets（保留 workos-simulator.html.bak-20260924 等历史文件）
scp -P 50222 dist-web-carrier.tar.gz root@220.154.128.28:/tmp/
ssh -p 50222 root@220.154.128.28 \
  "rm -rf /opt/overinsur/deploy/web/assets \
   && tar -xzf /tmp/dist-web-carrier.tar.gz -C /opt/overinsur/deploy/web \
   && rm /tmp/dist-web-carrier.tar.gz"
```

### 3.2 后端

```bash
# 1) 备份生产旧源文件
ssh -p 50222 root@220.154.128.28 \
  "cd /opt/overinsur/src/apps/carrier-service/src/modules/integration \
   && mkdir -p /tmp/integ-bak \
   && cp integration.service.ts v1.controller.ts dtos/integration.dto.ts /tmp/integ-bak/"
# 2) scp 覆盖 3 个文件到 /opt/overinsur/src 对应路径（md5 校验一致）
# 3) 重建镜像并重启（Docker 层缓存，实测构建约 30s）
ssh -p 50222 root@220.154.128.28 \
  "cd /opt/overinsur && docker compose build carrier-api \
   && docker compose up -d carrier-api"
```

### 3.3 模拟器

随 3.1 dist 发布，无需单独操作；发布后核对 md5 与本地一致。
