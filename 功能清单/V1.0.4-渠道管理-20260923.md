## 七、渠道档案

> **V1.0.3 重组：** 合并"渠道主数据管理"+"渠道层级与组织架构"主表部分，新增法律实体子表、业务员 Individual Producer 子表（本期建设）、扩展资质文件类型与银行账户类型。**US 业务必需字段集：** FEIN、Resident State、Business Entity License Number、渠道类型枚举（Agency/MGA/MGU/Surplus Lines Broker/Wholesaler/Direct Writer/TGA）。

### 7.1 渠道档案管理

**功能描述：** 维护渠道组织档案：渠道编号、英中文名、businessCountry（US/CN）、渠道类型、状态、归属分支机构；US 专属：FEIN、Resident State、Business Entity License Number、渠道类型枚举（Agency/MGA/MGU/Surplus Lines Broker/Wholesaler/Direct Writer/TGA）；CN 专属：统一社会信用代码、注册地、营业执照号。状态机：草稿→待审核→有效→暂停→终止/黑名单。档案变更全字段留痕。

| 操作名称 | 操作说明 |
|---|---|
| 新增渠道档案 | 录入渠道编号、英中文名、businessCountry（US/CN）、渠道类型、归属分支机构 |
| 录入 US 专属字段 | US 业务：FEIN、Resident State、Business Entity License Number、渠道类型枚举（Agency/MGA/MGU/Surplus Lines Broker/Wholesaler/Direct Writer/TGA） |
| 录入 CN 专属字段 | CN 业务：统一社会信用代码、注册地、营业执照号 |
| 编辑档案 | 修改档案字段，所有变更记录审计日志 |
| 提交审核 | 草稿→待审核 |
| 审核通过/驳回 | 待审核→有效（通过）/ 退回草稿（驳回，需填写驳回原因） |
| 暂停渠道 | 有效→暂停（合规异常或运营操作，需填写暂停原因） |
| 恢复渠道 | 暂停→有效 |
| 终止渠道 | 有效/暂停→终止（终态，不可恢复，需填写终止原因） |
| 加入黑名单 | 有效/暂停→黑名单（终态，重大合规违规，需审批） |
| 查看变更历史 | 全字段变更前后值对比、操作人、时间 |
| 批量导入 | 通过 Excel 批量导入渠道档案（按 businessCountry 区分模板） |

### 7.2 法律实体子表

**功能描述：** 新增法律实体子表：法人名称、EIN（US）/统一社会信用代码（CN）、注册州（US）/注册地（CN）、实体类型（LLC/Corp/Partnership，US）、注册资本。一个渠道可关联多个法律实体（如分支机构）。

| 操作名称 | 操作说明 |
|---|---|
| 新增法律实体 | 录入法人名称、EIN/统一社会信用代码、注册州/注册地、实体类型、注册资本 |
| 编辑法律实体 | 修改法律实体信息 |
| 设置主法律实体 | 标记该渠道的主法律实体（唯一） |
| 停用法律实体 | 不再使用该法律实体（保留记录可审计） |
| 查看法律实体列表 | 展示该渠道下所有法律实体及状态 |

### 7.3 联系人子表

**功能描述：** 维护渠道联系人：姓名 First/Last（US）/Full（CN）、职务、NPN（US 业务员联系人）、Email、Phone（CountryCode+Number）、Address（含 State/Zip，US）、是否主联。

| 操作名称 | 操作说明 |
|---|---|
| 新增联系人 | 录入姓名（First/Last 或 Full）、职务、NPN（US 业务员联系人）、Email、Phone、Address、是否主联 |
| 编辑联系人 | 修改联系人信息 |
| 设置主联系人 | 标记该渠道的主联系人（一个角色可多个主联） |
| 停用联系人 | 联系人离职/调岗时标记为停用 |
| 批量导入联系人 | 通过 Excel 批量导入联系人（按 businessCountry 区分模板） |

### 7.4 业务员 Individual Producer 子表（本期建设）

**功能描述：** 维护渠道下具体业务员（Individual Producer）：NPN、First/Last Name、SSN Last 4、Resident State、License States、License LOA、Appointment 列表（Carrier×State）、CE 学时进度、有效期、状态（Active/Expired/Surrendered/Revoked）。**美国监管口径下业务员是 Individual Appointment，不是机构 Appointment。** License 过期自动暂停该业务员所有 Appointment（联动第九章渠道授权）。

| 操作名称 | 操作说明 |
|---|---|
| 新增业务员 | 录入 NPN、First/Last Name、SSN Last 4、Resident State、License States、License LOA |
| 编辑业务员 | 修改业务员档案字段 |
| NPN 校验 | NPN 格式校验 + 唯一性校验（同一 NPN 不可重复登记） |
| License 登记 | 按 LOA（Line of Authority）维度登记 License States（如 AUTO/HOME/LIFE 等授权线） |
| Appointment 列表维护 | 维护业务员 Carrier×State Appointment 列表（来源：保司 Appointment ID，不可超保险公司对我司的 Appointment 范围） |
| CE 学时登记 | 登记业务员 CE Course 学时进度（按州×周期×已完成学时/应完成学时） |
| 状态变更 | 手动变更业务员状态（Active/Expired/Surrendered/Revoked）；License 过期自动触发 Expired + 暂停 Appointment |
| 批量导入业务员 | 通过 Excel 批量导入业务员档案 |
| 查看变更历史 | 全字段变更前后值对比、操作人、时间 |

### 7.5 资质文件子表

**功能描述：** 集中管理渠道组织和业务员的各类资质文件：US 扩展类型（营业执照/Business Entity License/E&O 保险/W-9/Producer License/CE Certificate）；CN 类型（营业执照/法人证件/经营许可证）。支持文件类型分类、有效期设置、到期提醒、审核确认。

| 操作名称 | 操作说明 |
|---|---|
| 上传文件 | 上传资质文件（按类型分类：营业执照/Business Entity License/E&O 保险/W-9/Producer License/CE Certificate 等） |
| 预览文件 | 在线预览文档/图片 |
| 下载文件 | 下载资质文件 |
| 替换文件 | 上传新版本替换旧版本（保留版本历史） |
| 删除文件 | 删除未在使用的文件（已使用文件不可删除，仅可置失效） |
| 设置有效期 | 登记资质文件的有效期（起止日期） |
| 到期提醒 | 临期前 30/60/90 天自动通知渠道主联系人 + 我司运营 |
| 审核 | 资质文件审核确认（审核人、时间、审核结论） |
| 批量上传 | 批量上传多个资质文件 |

### 7.6 银行账户子表

**功能描述：** 管理渠道收款银行账户：US 扩展类型（Checking/Savings/Escrow）+ Routing Number；CN 类型（基本户/一般户）。设置默认账户。

| 操作名称 | 操作说明 |
|---|---|
| 新增账户 | 录入账户类型（Checking/Savings/Escrow 或 基本户/一般户）、账户号、Routing Number（US）、开户行、账户名 |
| 编辑账户 | 修改账户信息 |
| 设置默认账户 | 标记该渠道的默认收款账户（唯一） |
| 删除账户 | 删除未使用的账户（已使用账户不可删除，仅可停用） |
| 查看变更历史 | 账户变更全字段留痕 |

### 7.7 组织层级

**功能描述：** 维护渠道组织层级：上级渠道、层级深度、业务线归属（多上级支持）、子渠道限额 ≤ 父渠道限额。支持层级树可视化。

| 操作名称 | 操作说明 |
|---|---|
| 新增层级关系 | 设置上级渠道、层级深度、业务线归属 |
| 调整层级 | 调整上级渠道（需校验子渠道限额 ≤ 父渠道限额） |
| 终止层级 | 终止上下级关系（保留历史可审计） |
| 多上级配置 | 支持一个渠道有多个上级（按业务线/产品分维度汇报） |
| Override 率配置 | 配置各层级上级对下级业绩的 Override 率 |
| 生效日期 | 登记层级关系生效日期（支持历史层级快照） |
| 冲突检测 | 检测循环引用、限额继承冲突 |
| 层级树查看 | 可视化展示渠道层级树（支持折叠/展开、按业务线切换） |

## 八、渠道合作

> **模块定位：** 管理我司与渠道的合作协议。一渠道可多协议，现行协议唯一；结算条款在合作详情只读展示，唯一编辑入口在渠道结算主数据（13.1），结算条款变更走补充协议。
>
> **协议状态机（八态）：** 草稿 DRAFT → 待签 PENDING_SIGN → **已签署 SIGNED（独立状态值）** → 已生效 ACTIVE → 即将到期 EXPIRING（到期前 30/60/90 天派生）→ 已到期 EXPIRED / 已终止 TERMINATED / 已废止 VOID。

### 8.1 合作协议管理

**功能描述：** 维护我司与渠道的合作协议：协议编号、协议类型（框架/补充/续签）、签订日期、生效起止、合作期限（长期/限期）、businessCountry。一渠道可多协议，现行协议唯一。状态机：草稿→待签→已签署→已生效→即将到期→已到期/已终止/已废止。

| 操作名称 | 操作说明 |
|---|---|
| 新增协议 | 录入协议编号、协议类型（框架/补充/续签）、签订日期、生效起止、合作期限、businessCountry |
| 编辑协议 | 修改协议字段（已生效协议仅可编辑非关键字段，关键字段变更走补充协议） |
| 签署登记 | 草稿→待签→已签署（上传签署附件，SIGNED 为独立状态值） |
| 生效 | 已签署→已生效（到达生效日期自动生效或手动推进，手动推进需二次确认） |
| 到期预警 | 即将到期（到期前 30/60/90 天派生） |
| 终止 | 已生效→已终止（需填写终止原因，终态） |
| 废止 | 已生效→已废止（重大违约或合规要求，需审批，终态） |
| 查看协议列表 | 展示该渠道下所有协议及状态 |

### 8.2 合作范围

**功能描述：** 维护合作范围：险种清单、地域清单（US 按州，CN 按省/市）、业务量约定。合作范围与渠道持牌州无交集时黄色警示。

| 操作名称 | 操作说明 |
|---|---|
| 新增险种 | 勾选合作的险种清单（AUTO/HOME/LIFE/HEALTH 等） |
| 新增地域 | US 按州勾选、CN 按省/市勾选 |
| 批量配置 | 批量勾选险种/地域、大区分组批量配置 |
| 业务量约定 | 登记业务量目标（保费/保单数/月度/季度/年度） |

### 8.3 结算条款只读+跳转

**功能描述：** 合作详情只读展示当前生效结算条款（佣金率、结算方式、结算周期、发票要求、付款账期），提供「维护结算条款」跳转链接进入财务模块渠道结算主数据页（唯一编辑入口）。**结算条款变更走补充协议，不直接改主协议。**

| 操作名称 | 操作说明 |
|---|---|
| 查看结算条款摘要 | 只读展示当前生效佣金率概要（险种/产品/州档位数量、最新版本号、最近更新时间）、结算方式、结算周期、发票要求、付款账期 |
| 跳转维护 | 提供「维护结算条款」链接，跳转第十三章渠道结算主数据页（自动带入当前渠道） |
| 查看补充协议链 | 展示该合作协议下的所有补充协议（含结算条款变更）及生效状态 |

### 8.4 协议附件

**功能描述：** 管理协议附件：合同扫描件、补充协议、变更函。

| 操作名称 | 操作说明 |
|---|---|
| 上传附件 | 上传协议合同扫描件、补充协议、变更函 |
| 预览 | 在线预览附件 |
| 下载 | 下载协议附件 |
| 替换 | 上传新版本替换旧版本 |
| 版本管理 | 保留附件历次版本，可对比；签署依据附件不可删除 |

### 8.5 续约登记

**功能描述：** **续约不设评估/谈判/决策环节**，运营直接登记续约：填新到期日、上传续约合同即生效，状态由即将到期/已到期回到已生效。

| 操作名称 | 操作说明 |
|---|---|
| 发起续约登记 | 录入新到期日、续约说明/条件变更备注 |
| 上传续约合同 | 上传续约合同扫描件 |
| 续约生效 | 续约登记保存后延长合作协议到期日，状态回到已生效 |
| 不续期自然到期 | 到期不续则协议自然到期，需提前退出的走终止流程 |

### 8.6 协议到期预警

**功能描述：** 协议到期前 N 天（30/60/90 天）预警，推送渠道主联系人与我司运营。

| 操作名称 | 操作说明 |
|---|---|
| 到期列表 | 展示 30/60/90 天内到期的协议清单（按渠道/到期日排序，剩余天数倒序） |
| 提醒通知 | 90/60/30 天自动推送邮件给渠道主联系人 + 系统通知给我司运营，发送状态可查 |
| 续约登记入口 | 从到期列表直接进入续约登记流程 |

## 九、渠道授权

> **V1.0.3 重组：** 6 开关 + 限额继承 + 前置校验三件套 + Appointment 联动 + 特约代码。授权关联 Individual Producer（业务员 ID，非渠道 ID）。授权状态机：Pending→Active→Suspended→Withdrawn→Expired。

### 9.1 授权主表管理

**功能描述：** 维护授权：授权编号、Carrier、Product、LOB、State、Appointment 起止。**关联 Individual Producer（业务员 ID，而非渠道 ID）**，美国口径下是 Individual Appointment。来源 Carrier Appointment ID（不能超保险公司对我司的 Appointment 范围）。授权类型：Open Appointment / Named Appointment。唯一性约束：同渠道同产品同时只能有一条有效授权。状态机：Pending→Active→Suspended→Withdrawn→Expired。

| 操作名称 | 操作说明 |
|---|---|
| 新增授权 | 录入授权编号、Carrier、Product、LOB、State、Appointment 起止、关联业务员 ID、来源 Carrier Appointment ID、授权类型（Open/Named） |
| 编辑授权 | 修改授权字段（已 Active 授权仅可编辑非关键字段） |
| 提交 | Pending→待激活 |
| 激活 | 待激活→Active（通过前置校验三件套） |
| 暂停 | Active→Suspended（合规异常触发或运营手动操作） |
| 撤回 | Active/Suspended→Withdrawn（终态，需填写撤回原因） |
| 过期 | Active→Expired（到达 Appointment 截止日自动派生） |
| 查看授权列表 | 展示渠道/业务员下所有授权及状态（支持按 Carrier/Product/State 筛选） |

### 9.2 6 开关权限配置

**功能描述：** 授权权限为 6 个独立开关：**可报价 Quote / 可出单 Bind / 可批改 Endorse / 可续保 Renew / 可退保 Cancel / 可理赔 Claim**。每个开关独立配置，支持批量配置与权限矩阵查看。

| 操作名称 | 操作说明 |
|---|---|

## 十二、渠道订单（独立子模块，本期建设）

> **订单链路：** 渠道商上报询价（Quote，12.1）→ 报价确认 → 投保申请 → 核保登记 → 出单成交（Bound Order，12.2）→ 状态机（12.3）→ 与保司账单条目绑定关联（carrier_bill_item_id / LINKED）后进入 13 渠道结算对账；询价/失效/撤回/拒保订单不进结算。
>
> **6 种订单类型：** Quote / New Business / Renewal / Endorsement / Cancellation / Reinstatement。
> **16 状态：** DRAFT → QUOTE_SUBMITTED → QUOTED → QUOTE_ACCEPTED → APPLICATION_SUBMITTED → UNDERWRITING → BOUND → LINKED → PENDING_SETTLEMENT → SETTLED；异常终态 DECLINED / QUOTE_EXPIRED / QUOTE_WITHDRAWN / VOID；退保 CHARGEBACK_PENDING → CHARGEBACK_DONE；批改经"调整中"回 SETTLED。
> 保司 API 开放前报价采用登记制（人工报价/费率档案试算）。

### 12.1 询价订单与报价管理（Quote）

**功能描述：** 渠道商上报客户询价信息的订单（Quote Order，渠道订单的起点）。渠道商在渠道门户或由运营代录创建询价订单：选择意向 Carrier/Product/LOB/State，录入客户基本信息（客户类型 individual/commercial、投保人 Named Insured、联系方式）、被保人、风险地址、按险种风险明细（车险 VIN/车型/年款/驾驶记录；房屋险建造年份/结构等）、保障意向（Coverage Requested）。提交前执行前置校验三件套（产品可售州 ∩ 渠道持牌州 ∩ 合作协议有效期）与 6 开关之"可报价 can_quote"校验。保司 API 开放前报价采用登记制（人工报价/费率档案试算），支持多产品报价对比、重新报价（Re-quote，quote_version 递增）、报价有效期（Quote Valid Until，通常 30 天，到期自动 QUOTE_EXPIRED）。报价确认后转投保申请，出单（BOUND）后转化为 New Business 成交订单（parent_order_id 关联 12.2）。询价/报价失效/撤回/拒保订单**不进结算**。支持询价跟进记录与转化漏斗统计。

| 操作名称 | 操作说明 |
|---|---|
| 创建询价订单 | 新建询价订单（order_type=Quote，状态 DRAFT 草稿），支持保存草稿 |
| 选择意向产品 | 选择意向 Carrier/Product/LOB/State，支持多选用于多产品报价对比 |
| 录入客户信息 | 录入客户类型（individual/commercial）、投保人 Named Insured、联系方式（电话/邮箱） |
| 录入被保人/风险地址 | 录入被保人、风险地址 |
| 录入风险明细 | 按险种录入结构化风险明细（车险：VIN/车型/年款/驾驶员记录；房屋险：建造年份/结构/保额意向） |
| 录入保障意向 | 录入保障意向（保额/保障需求描述 Coverage Requested） |
| 前置校验 | 提交前校验：产品可售州 ∩ 渠道持牌州 ∩ 合作协议有效期 + can_quote 开关；不通过禁止提交并提示原因 |
| 提交询价 | DRAFT→QUOTE_SUBMITTED（询价已上报），记录来源（Portal 自助/业务员代报/运营代录） |
| 登记报价 | 保司 API 开放前：登记线下/费率档案试算报价——Quote Number、报价保费、保费明细（费率/折扣/Premium Tax 预估/Policy Fees 预估）、报价有效期；状态→QUOTED |
| 重新报价 | Re-quote 生成新版本报价（quote_version 递增），保留历史版本 |
| 多产品报价对比 | 同一询价下多产品报价横向对比（保费/保障/费率） |
| 导出报价单 | 报价单导出 PDF 发送客户 |
| 报价确认 | 客户接受报价：QUOTED→QUOTE_ACCEPTED，记录确认时间 |
| 转投保申请 | 报价确认后完善客户信息、上传核保资料、电子签名并提交投保申请：→APPLICATION_SUBMITTED→UNDERWRITING |
| 核保进度登记 | 登记核保进度与结果（自动通过/人工核保/加费协商/拒保）；拒保→DECLINED 并记录原因 |
| 客户撤回 | 客户放弃投保：→QUOTE_WITHDRAWN（终态，保留记录可审计，不进结算） |
| 报价失效处理 | 定时任务扫描超过 Quote Valid Until 未确认的报价：自动→QUOTE_EXPIRED；临期（如提前 7 天）提醒业务员跟进 |

| 出单转化 | 核保通过、保司出单后：UNDERWRITING→BOUND，Quote 订单转化为 New Business 成交订单（parent_order_id 关联 12.2），触发佣金计算事件 |
| 询价跟进 | 记录跟进日志（沟通内容/下次跟进时间），到期推送跟进提醒 |
| 询价列表 | 询价订单列表（按渠道/业务员/Carrier/Product/State/状态/报价有效期/来源筛选，关键字搜索） |
| 询价详情 | 查看询价全字段 + 报价版本历史 + 状态流转 + 跟进记录 + 转化成交订单 |
| 转化漏斗统计 | 统计询价数→报价数→报价确认数→投保申请数→出单成交数及各环节转化率（按渠道/业务员/产品/时间段） |

### 12.3 订单状态机

**功能描述：** 订单全生命周期状态机，覆盖询价前段（12.1 管理）与成交后段：①询价前段 DRAFT（草稿）→QUOTE_SUBMITTED（询价已上报）→QUOTED（已报价）→QUOTE_ACCEPTED（报价已确认）→APPLICATION_SUBMITTED（投保申请已提交）→UNDERWRITING（核保中）；②出单后段 BOUND（已成交，回填保单号，Quote 转化为 New Business）→LINKED（已绑定账单）→PENDING_SETTLEMENT（待结算）→SETTLED（已结算）；③异常分支：退保→CHARGEBACK_PENDING→CHARGEBACK_DONE（终态）/批改→调整中→SETTLED（更新金额）；④终态：DECLINED（已拒保，不进结算）、QUOTE_EXPIRED（报价失效）、QUOTE_WITHDRAWN（询价撤回）、VOID（已作废）。

| 拒保流转 | 核保拒保转 DECLINED（终态，不进结算），通知渠道 |
| 追回处理 | 退保触发追回流程（关联退保追回配置 13.10） |
| 批改处理 | 批改触发调整流程（更新保费/佣金金额） |
| 作废 | 错误订单作废（保留记录可审计） |
| 状态查看 | 查看订单全量状态流转历史（操作人/时间/前后值） |

## 十三、渠道结算

> **资金四段式流转（关键业务约束）：** ① 客户向保司投保付款 → ② 保司收保费按协议返点给我司（上游结算，属保司模块） → ③ 我司收到保司返点按合作协议付给渠道（本模块，下游结算） → ④ 渠道收到佣金。两侧通过"保司账单条目 ID"跨模块关联但分属不同模块。
>
> **结算主数据唯一编辑入口在财务模块**，合作详情只读+跳转；结算条款变更走补充协议。上游账单仅支持 CSV/Excel 导入，不做账单解析、不做 API 拉单。

### 13.1 结算主数据

**功能描述：** 维护渠道结算参数：渠道×Carrier×Product×LOB×State 维度的佣金率（Commission Rate）、结算方式（ACH/支票/电汇/平台聚合）、结算周期（月/季/年）、税务处理（Tax Treatment）；含阶梯比例、Contingent Commission、Premium Tax 配置。**财务模块为唯一编辑入口**，合作详情只读+跳转。变更历史留痕。

| 操作名称 | 操作说明 |
|---|---|
| 维护主数据 | 维护渠道结算参数（渠道×Carrier×Product×LOB×State → Commission Rate/Settlement Method/Period/Tax Treatment） |
| 配置阶梯比例 | 按保费区间配置阶梯佣金比例 |
| 配置 Contingent Commission | 配置 Loss Ratio 阈值→触发比例、核算周期（年度）、结算方式 |
| 配置 Premium Tax | 按州×业务类型（Admitted/Surplus Lines）配置税率、代收代缴方 |
| 变更历史 | 主数据变更留痕（版本/操作人/时间） |

### 13.2 对账流程

**功能描述：** 保司结算清单（承保/退保/批单）CSV/Excel 导入，自动匹配渠道订单（保单号精确 / 投保人+LOB+日期 fallback），分流完全/部分/无匹配；按单×比例生成渠道结算明细，按周期×Carrier×渠道汇总结算单。

| 操作名称 | 操作说明 |
|---|---|
| 导入保司结算清单 | CSV/Excel 导入（仅文件导入，承保/退保/批单三类） |
| 自动匹配 | 按保单号精确匹配，失败按投保人+LOB+Effective Date fallback |
| 匹配分流 | 完全匹配 / 部分匹配 / 无匹配分流（部分、无匹配进入差异处理 13.4） |
| 生成结算明细 | 按单×比例计算应付渠道佣金，生成明细行 |
| 汇总结算单 | 按结算周期×Carrier×渠道汇总生成结算单（见 13.3） |

### 13.3 结算单结构

**功能描述：** 结算单：渠道 ID、结算周期、生成日期；明细行（保单号/产品/保费/佣金率/应付佣金/备注）；调整项（补扣/追回/预支抵扣/人工调整）；应付总额、支付方式、收款账户。状态机：待审批→已审批→支付中→已支付→已对账。**有未关闭差异时禁止关单。**

| 操作名称 | 操作说明 |
|---|---|

| 人工调整 | 人工调整结算金额（需审批） |
| 审批 | 结算单审批流（主管→财务→总经理，大额加签） |
| 生成支付指令 | 审批通过后生成支付指令（关联 13.12） |
| 对账 | 与渠道对账确认 |
| PDF 导出 | 结算单导出 PDF |

### 13.4 差异处理轻量闭环

## 十四、渠道政策

> **单向发布口径：我司下发保险公司政策，不接收渠道上报。** 5 类政策：Underwriting Guideline / Rate Manual / Product Bulletin / Compliance Bulletin / Carrier Notice。时效：Permanent（永久）/ Term（Days/Months/Quarter/Years，自动到期）。状态机：Draft→Pending Publish→Published→Effective→Expiring→Expired/Superseded/Withdrawn。

### 14.1 政策主表管理

**功能描述：** 管理政策主表：政策编号、类型（5 类）、来源 Carrier、适用 LOB/State/渠道（All/Named）、时效（Permanent/Term）、Effective/Expiration Date、Auto-Expire 开关、正文与附件（Rate Manual PDF、Underwriting Matrix）。支持发布审批、撤销（终态）、替代关系维护（新政策 Supersedes 旧政策）。

| 操作名称 | 操作说明 |
|---|---|
| 新增政策 | 录入编号、类型、来源 Carrier、适用 LOB/State/渠道、时效、正文、附件 |
| 编辑政策 | 修改政策字段（已 Published 政策仅可编辑非关键字段） |
| 提交发布 | Draft→Pending Publish |
| 发布审批 | 主管审批后 Pending Publish→Published |
| 生效 | 到达 Effective Date 自动 Published→Effective |
| 到期派生 | 到期前 30 天派生 Expiring；到期自动 Expired（Auto-Expire） |
| 撤销 | Effective/Published→Withdrawn（终态，需填写撤销原因） |
| 替代关系维护 | 维护 New Policy Supersedes 旧政策链（旧政策自动 Superseded） |

### 14.2 政策类型示例

**功能描述：** 5 类政策按类型录入具体内容：费率政策（某产品某州费率 ±X%）、核保政策（收紧核保规则）、佣金政策（促销期佣金率上浮）、范围政策（新开/撤出州）、促销政策（限时优惠活动）。关联具体产品/州（防冲突与联动用）。

| 操作名称 | 操作说明 |
|---|---|
| 费率政策录入 | 录入产品费率调整（某产品某州 ±X%） |
| 核保政策录入 | 录入核保规则变化（如健康告知增加项） |
| 佣金政策录入 | 录入佣金率变化（如促销期上浮） |
| 范围政策录入 | 录入业务范围变化（新开 N 州/撤出 M 州） |
| 促销政策录入 | 录入限时优惠政策 |

### 14.3 防冲突规则

**功能描述：** 发布前校验同一产品同一类型政策有效期不可重叠；强制发布需主管审批并记录原因。

| 操作名称 | 操作说明 |
|---|---|
| 冲突校验 | 发布前校验同一产品同一类型政策有效期是否重叠 |
| 冲突展示 | 展示具体冲突项（产品/类型/重叠期） |
| 强制发布（需审批） | 冲突情况下强制发布（需主管审批+记录原因） |

### 14.4 政策联动

**功能描述：** 政策生效触发联动：Underwriting 变更自动生成培训任务（M4）、Rate 变更触发结算比例复核（推送财务 13.1）、范围变更暂停相关授权；生效前 N 天向受影响渠道推送通知。

| 操作名称 | 操作说明 |
|---|---|
| 联动配置 | 配置政策类型→联动动作（暂停授权/结算复核/培训任务/通知） |
| 生效前通知 | 生效前 N 天向受影响渠道推送通知 |
| 培训任务联动 | Underwriting 变更自动生成培训任务（M4） |
| 结算复核联动 | Rate 变更触发结算比例复核（推送财务 13.1） |

### 14.5 单向下发

**功能描述：** 政策生效后自动下发到受影响渠道（渠道门户接收清单）；**不接收渠道上报**。我司侧查看接收记录（已读/未读）。

| 操作名称 | 操作说明 |
|---|---|
| 政策下发 | 政策生效后自动下发到受影响渠道 |
| 渠道门户接收 | 渠道门户展示接收政策清单（门户端 P2） |
| 查看接收记录 | 我司侧查看渠道接收记录（已读/未读） |
